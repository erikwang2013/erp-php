# Flutter মাল্টি-প্ল্যাটফর্ম PC স্টাইল লেআউট — ডিজাইন স্পেক

তারিখ: 2026-05-18

## লক্ষ্য

macOS, Windows ডেস্কটপ প্ল্যাটফর্ম সক্রিয় করুন, নিশ্চিত করুন iOS (iPhone + iPad), macOS, Windows, Linux সব প্ল্যাটফর্মে PC ম্যানেজমেন্ট ব্যাকএন্ড স্টাইল লেআউট (সাইডবার + টপবার + কনটেন্ট এরিয়া) ব্যবহৃত হয়, মোবাইলে ড্রয়ার মেনু দিয়ে অ্যাডাপ্ট করা হয়।

## প্ল্যাটফর্ম কৌশল

| প্ল্যাটফর্ম | অবস্থা | ব্যাখ্যা |
|------|------|------|
| Linux | সক্রিয় | কোনো কাজ লাগবে না |
| macOS | সক্রিয় করতে হবে | `flutter config --enable-macos-desktop` |
| Windows | সক্রিয় করতে হবে | `flutter config --enable-windows-desktop` |
| iOS | বিদ্যমান | একই সাথে iPhone (মোবাইল লেআউট) এবং iPad (ডেস্কটপ লেআউট) কভার করে |
| Web | বিদ্যমান | কোনো কাজ লাগবে না |

iPad-এর আলাদা প্ল্যাটফর্ম টার্গেট নেই, রেসপন্সিভ ব্রেকপয়েন্টে TABLET ধরে ডেস্কটপ লেআউট পায়।

## রেসপন্সিভ ব্রেকপয়েন্ট

| ব্রেকপয়েন্ট | রেঞ্জ | লেআউট মোড |
|------|------|----------|
| PHONE | 0 - 767 | ড্রয়ার মেনু (AppBar + Drawer) |
| TABLET | 768 - 1199 | ভাঁজযোগ্য সাইডবার (ডিফল্ট ভাঁজ 64px) |
| DESKTOP | 1200 - 2460 | সাইডবার (ডিফল্ট প্রসারিত 240px) |

iPad পোর্ট্রেট ন্যূনতম প্রস্থ 768px, TABLET ধরে, সাইডবার লেআউট পায়।
iPhone-এর প্রস্থ সবসময় 768px-এর কম, PHONE ধরে, ড্রয়ার মেনু পায়।

## ফাইল পরিবর্তন

### 1. main.dart — ব্রেকপয়েন্ট কনফিগ

- `PHONE`: 0-767, `TABLET`: 768-1199, `DESKTOP`: 1200-2460
- বাকি কোড অপরিবর্তিত

### 2. admin_layout.dart — রেসপন্সিভ নেভিগেশন সুইচিং

- `_isPhone`: PHONE ব্রেকপয়েন্টে সত্য
- `_buildPhoneLayout()`: Scaffold + AppBar + Drawer, Drawer-এর ভেতরের NavigationDrawer ডেস্কটপ সাইডবারের সাথে একই মেনু আইটেম পুনরায় ব্যবহার করে
- `_buildDesktopLayout()`: বিদ্যমান Row লেআউট (সাইডবার + টপবার + কনটেন্ট এরিয়া)
- TABLET-এ সাইডবার ডিফল্ট ভাঁজ, DESKTOP-এ ডিফল্ট প্রসারিত

### 3. app_theme.dart — ডার্ক থিম পূরণ

- কম্পোনেন্ট স্টাইলগুলো প্রাইভেট কনস্ট্যান্টে আলাদা করা হয় `_dataTableTheme`, `_cardTheme`, `_inputDecorationTheme`, `_dividerTheme`
- লাইট ও ডার্ক থিম একই কম্পোনেন্ট স্টাইল সেট পুনরায় ব্যবহার করে
- ডার্ক থিম Material 3 + একই seed + dark ব্রাইটনেস ব্যবহার করে
