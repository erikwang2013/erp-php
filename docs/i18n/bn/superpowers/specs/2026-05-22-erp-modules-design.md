## 1. ওভারভিউ

বিদ্যমান `service/` সিস্টেম ম্যানেজমেন্ট বেসের উপরে পণ্য-বিক্রয়-স্টক, ফাইন্যান্স, CRM তিনটি ব্যবসায়িক ডোমেইন সম্প্রসারিত করে সম্পূর্ণ ERP সিস্টেম গড়ে তোলা হয়।
সব কোড `service/app/`-এর অধীনে মনোলিথ ডিপ্লয় হয়, মডিউল ডিরেক্টরি অনুযায়ী স্তরে স্তরে সাজানো।

### 1.1 ফেজ পরিকল্পনা

| ফেজ | মডিউল | ব্যাখ্যা |
|------|------|------|
| Phase 1 | পণ্য বেস ডেটা + ক্রয় + বিক্রয় + ইনভেন্টরি + ফাইন্যান্স + CRM | মূল ব্যবসায়িক ক্লোজড-লুপ |
| Phase 2 | ম্যানুফ্যাকচারিং ম্যানেজমেন্ট + প্রজেক্ট ম্যানেজমেন্ট | পরবর্তী সম্প্রসারণ |

### 1.2 টেক স্ট্যাক (বিদ্যমান অনুসরণ)

- PHP 8.3+, webman v2, MySQL 8.0+
- প্রাইমারি কি BIGINT snowflake-php দিয়ে তৈরি হয়
- API স্তরের ID hashids দিয়ে এনক্রিপ্ট/ডিক্রিপ্ট হয়
- JWT অথেনটিকেশন, সংবেদনশীল ডেটা এনক্রিপশন সব erikwang2013/* সিরিজ প্যাকেজ দিয়ে হয়
- টেবিল প্রিফিক্স `erp_`, সফট ডিলিট, গ্লোবাল ফাংশনে `\` যোগ হয় না

## 2. প্রজেক্ট স্ট্রাকচার

```
service/app/
├── admin/controller/          # 系统管理控制器（已有，保持不变）
├── api/v1/controller/         # 客户端API（已有 + 扩展）
├── common/                    # 共享工具（已有 Snowflake/Hashids/Encryption）
├── middleware/                # 全局中间件（已有7个）
├── model/                     # 所有数据模型（跨模块共享）
├── service/                   # 业务逻辑层（按模块分目录）
│   ├── product/               # 商品与基础数据
│   ├── purchase/              # 采购
│   ├── sales/                 # 销售
│   ├── inventory/             # 库存
│   ├── finance/               # 财务
│   └── crm/                   # CRM
├── controller/                # 业务模块控制器
│   ├── product/               # 商品基础数据
│   ├── purchase/              # 采购
│   ├── sales/                 # 销售
│   ├── inventory/             # 库存
│   ├── finance/               # 财务
│   └── crm/                   # CRM
├── queue/                     # 队列任务（已有 + 业务队列）
├── process/                   # 进程（已有 Http, Monitor）
└── functions.php              # 全局辅助函数（已有）
```

### 2.1 লেয়ার দায়িত্ব

| স্তর | ফাইল অবস্থান | দায়িত্ব |
|----|----------|------|
| Controller | `app/controller/{module}/` | প্যারামিটার যাচাই, রেসপন্স ফরম্যাট, Service কল |
| Service | `app/service/{module}/` | ব্যবসায়িক লজিক, ক্রস-মডিউল লিংকেজ, ট্রানজেকশন ম্যানেজমেন্ট |
| Model | `app/model/` | ডেটা মডেল, সম্পর্ক, কোয়েরি স্কোপ, encryptable trait |

## 5. API রাউট

`/admin/*` নেমস্পেস অনুসরণ, সম্পূর্ণ মিডলওয়্যার চেইন (Auth → Permission → OperationLog)।

```
# 商品基础数据
/admin/product/*          商品/分类/品牌 CRUD
```

## 6. ক্রস-মডিউল ডেটা ফ্লো

```
采购收货 → inventory_flow(入库) → inventory(+数量) → cost_record(重算均价)
       → finance_ar_ap(应付)

销售发货 → inventory_flow(出库) → inventory(-数量) → cost_record(记录成本)
       → finance_ar_ap(应收)

收款单核销 → finance_ar_ap(已收更新) → cash_journal(收入记录)
付款单核销 → finance_ar_ap(已付更新) → cash_journal(支出记录)

盘点差异 → inventory_flow(盘盈入库/盘亏出库) → inventory(调整)

费用报销(已打款) → finance_payment(自动生成) → cash_journal(支出记录)
```

বাস্তবায়ন পদ্ধতি: প্রতিটি ব্যবসায়িক অপারেশন শেষে ইভেন্ট দিয়ে পরবর্তী অ্যাকশন ট্রিগার হয়, ক্রস-মডিউলে সরাসরি Service কল করা হয় না।

## 7. Excel/PDF এক্সপোর্ট

- সব লিস্ট পেজ `?export=excel` প্যারামিটার সাপোর্ট করে, স্টাইলসহ .xlsx ফাইল তৈরি হয়
- ড্যাশবোর্ড প্যানেল `?export=pdf` সাপোর্ট করে, চার্টসহ PDF রিপোর্ট আউটপুট
- সংবেদনশীল ফিল্ড (টাকা, ফোন নম্বর ইত্যাদি) এক্সপোর্টের সময় EncryptionService দিয়ে মাস্ক হয়
- বিদ্যমান ExportController বেস ক্লাস পুনরায় ব্যবহার, প্রতিটি মডিউল কন্ট্রোলার উত্তরাধিকার নিয়ে নিজের এক্সপোর্ট কলাম ডেফিনিশন বাস্তবায়ন করে
