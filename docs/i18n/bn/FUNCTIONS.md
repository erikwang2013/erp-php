## 1. সিস্টেম ম্যানেজমেন্ট

### 1.1 ইউজার ম্যানেজমেন্ট
- অ্যাডমিন অ্যাকাউন্টের সম্পূর্ণ লাইফসাইকেল ম্যানেজমেন্ট (তৈরি/এডিট/ডিলিট/সক্রিয়-নিষ্ক্রিয়)
- ব্যাচ অপারেশন: ব্যাচ ডিলিট, ব্যাচ সক্রিয়/নিষ্ক্রিয়
- Excel দিয়ে ব্যাচ ইউজার ইমপোর্ট, লাইন-বাই-লাইন ভ্যালিডেশন + এরর রিপোর্ট
- পাসওয়ার্ড bcrypt হ্যাশে সংরক্ষিত, পাসওয়ার্ড পরিবর্তনে পুরনো পাসওয়ার্ড নিশ্চিতকরণ প্রয়োজন
- ডিলিট ইত্যাদি সংবেদনশীল অপারেশনে বর্তমান ইউজারের পাসওয়ার্ড দ্বিতীয়বার নিশ্চিতকরণ প্রয়োজন
- মোবাইল/ইমেইল/আইডি কার্ড নম্বর এনক্রিপ্টেড সংরক্ষণ, লিস্টে স্বয়ংক্রিয় ডিসেন্সিটাইজেশন

### 1.2 রোল পারমিশন (RBAC)
- রোল ম্যানেজমেন্ট: তৈরি/এডিট/ডিলিট, slug ইউনিক আইডেন্টিফায়ার
- পারমিশন ট্রি: সীমাহীন স্তরের ট্রি স্ট্রাকচার, তিন ধরনের — মেনু (ন্যাভিগেশন দৃশ্যমান), বাটন (পেজের ভিতরের অপারেশন), API (ইন্টারফেস অ্যাক্সেস)
- পারমিশন আইডেন্টিফায়ার ফরম্যাট: `{method}.{path}`, যেমন `get.admin/product`、`post.admin/user/batch/destroy`
- রোল-পারমিশন ম্যানি-টু-ম্যানি সম্পর্ক, সুপার অ্যাডমিন সব পারমিশন চেক স্কিপ করে
- AdminPermission মিডলওয়্যার Redis-এ ইউজার পারমিশন ক্যাশ করে (TTL=60s)

### 1.3 সিস্টেম কনফিগারেশন
- কী-ভ্যালু স্টোরেজ, গ্রুপ ম্যানেজমেন্ট সাপোর্ট
- ভ্যালু টাইপ: স্ট্রিং/ইন্টিজার/বুলিয়ান/JSON/অ্যারে

### 1.4 অপারেশন অডিট
- সব POST/PUT/DELETE অপারেশন স্বয়ংক্রিয় রেকর্ড
- অপারেটর, অ্যাকশন, মেথড, পাথ, IP, প্যারামিটার (সংবেদনশীল ফিল্ড ডিসেন্সিটাইজড), সময় রেকর্ড
- 8 প্ল্যাটফর্ম সোর্স অটো ডিটেকশন (Web/Flutter/HarmonyOS/API ইত্যাদি)
- শুধুমাত্র রিড-অনলি কোয়েরি, ডিলিট বা মডিফাই করা যায় না

### 1.5 নিরাপত্তা সুরক্ষা
- 18 স্তরের ডিফেন্স-ইন-ডেপথ: HTTP মেথড রেস্ট্রিকশন, XSS/SQL ইনজেকশন/পাথ ট্রাভার্সাল/কমান্ড ইনজেকশন/CSRF ইন্টারসেপশন
- ক্লিক ক্যাপচা (লগইন/রেজিস্ট্রেশনে বাধ্যতামূলক ভ্যালিডেশন)
- Redis স্লাইডিং উইন্ডো রেট লিমিট (Lua অ্যাটমিক, ডিফল্ট ৬০ বার/মিনিট)
- অ্যাকাউন্ট লক: ৫ বার ব্যর্থ হলে ১৫ মিনিট লক
- কনকারেন্ট সেশন লিমিট: একই ইউজারের সর্বোচ্চ ৩টি বৈধ Token
- CSP হেডার, security.txt (RFC 9116)
- সংবেদনশীল অপারেশনে র্যান্ডম দ্বিতীয় ভেরিফিকেশন (poster-php)

## 2. পণ্য ও বেস ডেটা

## 3. ক্রয় ম্যানেজমেন্ট

### 3.1 ক্রয় আবেদন
- ডিপার্টমেন্ট/ব্যক্তি ক্রয় প্রয়োজনীয়তা জমা দেয়
- অনুমোদন প্রক্রিয়া: অপেক্ষমাণ → অনুমোদিত/প্রত্যাখ্যাত → অর্ডারে রূপান্তরিত
- অনুমোদন ওয়ার্কফ্লো ইঞ্জিনে সংযোগযোগ্য

### 3.2 ক্রয় অর্ডার
- সাপ্লায়ার, পণ্য বিস্তারিত (পরিমাণ, ইউনিট মূল্য, টাকার অঙ্ক) সংযুক্ত
- স্ট্যাটাস: অপেক্ষমাণ রিভিউ → রিভিউড → আংশিক রিসিভ → রিসিভড → বাতিল
- আবেদনের ভিত্তিতে তৈরি করা যায়, সরাসরিও তৈরি করা যায়

### 3.3 ক্রয় রিসিভ (ক্রস-মডিউল লিংকেজ)
- অর্ডার অনুযায়ী রিসিভ, ব্যাচ রিসিভ সাপোর্ট
- রিসিভ স্বয়ংক্রিয় ট্রিগার: ① স্টক-ইন (মুভিং ওয়েটেড এভারেজ কস্ট) ② AP রেকর্ড তৈরি ③ অর্ডারের রিসিভড পরিমাণ আপডেট

### 3.4 ক্রয় রিটার্ন
- সাপ্লায়ারে ফেরত, স্টক-আউট রিভার্সাল তৈরি

### 3.5 সাপ্লায়ার সেটেলমেন্ট
- সাপ্লায়ার অনুযায়ী সামারি: ক্রয় পরিমাণ, পরিশোধিত, পরিশোধযোগ্য
- স্ট্যাটাস: আনসেটেলড/আংশিক সেটেলড/সেটেলড

## 4. বিক্রয় ম্যানেজমেন্ট

### 4.1 কোটেশন
- কাস্টমারকে মূল্য জানানো, সেলস অর্ডারে রূপান্তর সাপোর্ট
- স্ট্যাটাস: ড্রাফ্ট → কোটেড → অর্ডারে রূপান্তরিত → মেয়াদোত্তীর্ণ

### 4.2 সেলস অর্ডার
- কাস্টমার, পণ্য বিস্তারিত (পরিমাণ, ইউনিট মূল্য, ডিসকাউন্ট) সংযুক্ত
- স্ট্যাটাস: অপেক্ষমাণ রিভিউ → রিভিউড → আংশিক ডেলিভারি → ডেলিভারড → বাতিল

### 4.3 সেলস ডেলিভারি (ক্রস-মডিউল লিংকেজ)
- অর্ডার অনুযায়ী ডেলিভারি, ব্যাচ ডেলিভারি সাপোর্ট
- ডেলিভারি স্বয়ংক্রিয় ট্রিগার: ① স্টক-আউট (মুভিং ওয়েটেড এভারেজ কস্ট) ② AR রেকর্ড তৈরি ③ অর্ডারের ডেলিভারড পরিমাণ আপডেট

### 4.4 সেলস রিটার্ন
- কাস্টমার রিটার্ন, স্টক-ইন রিভার্সাল তৈরি

### 4.5 কাস্টমার সেটেলমেন্ট ও মুনাফা
- কাস্টমার অনুযায়ী সামারি: বিক্রয় পরিমাণ, প্রাপ্ত, প্রাপ্য
- অর্ডার/পণ্য/কাস্টমার ডাইমেনশনে মুনাফা হিসাব

## 5. ইনভেন্টরি ম্যানেজমেন্ট

### 5.1 রিয়েল-টাইম ইনভেন্টরি
- চার-ডাইমেনশনাল নির্ভুলতা: গুদাম + লোকেশন + ব্যাচ + SKU
- মাল্টি-গুদাম, মাল্টি-লোকেশন সাপোর্ট
- রিয়েল-টাইম ইনভেন্টরি কোয়েরি

### 5.2 ইন/আউট স্টক ফ্লো
- সব ইনভেন্টরি পরিবর্তন ইউনিফাইড রেকর্ড (দিক, পরিমাণ, কস্ট প্রাইস, সোর্স ডকুমেন্ট নম্বর, সময়)

### 5.3 ব্যাচ ট্র্যাকিং
- উৎপাদন তারিখ, মেয়াদ শেষ তারিখ, ব্যাচ নম্বর
- ইন/আউট স্টকে ব্যাচ রেকর্ড

### 5.4 সিরিয়াল নম্বর ট্র্যাকিং
- ইউনিক সিরিয়াল নম্বর ম্যানেজমেন্ট
- ইন/আউট স্টকে স্ট্যাটাস রেকর্ড (স্টকে/আউট)

### 5.5 কস্ট অ্যাকাউন্টিং
- মুভিং ওয়েটেড এভারেজ মেথড
- সূত্র: নতুন গড় = (পুরনো স্টক মোট মূল্য + এইবার ইন স্টক মোট মূল্য) / (পুরনো স্টক পরিমাণ + এইবার ইন স্টক পরিমাণ)
- প্রতিটি ইন স্টকে স্বয়ংক্রিয় পুনঃগণনা, আউট স্টক বর্তমান গড় মূল্যে কস্ট

### 5.6 ইনভেন্টরি ট্রান্সফার
- গুদামের মধ্যে/লোকেশনের মধ্যে ট্রান্সফার
- স্ট্যাটাস: অপেক্ষমাণ ট্রান্সফার → আউট করা হয়েছে → ইন নেওয়া হয়েছে → সম্পন্ন
- স্বয়ংক্রিয় আউট/ইন ফ্লো তৈরি

### 5.7 কাউন্ট ম্যানেজমেন্ট
- প্ল্যান কাউন্ট (গুদাম/ক্যাটাগরি অনুযায়ী) + ডাইনামিক কাউন্ট (SKU অনুযায়ী)
- বুক ভ্যালু vs প্রকৃত কাউন্ট রেকর্ড
- পার্থক্য স্বয়ংক্রিয়ভাবে সারপ্লাস/শর্টেজ ফ্লো তৈরি

### 5.8 ইনভেন্টরি অ্যালার্ট
- SKU+গুদাম অনুযায়ী উপরে/নিচে সীমা সেট
- নিম্ন সীমার নিচে/উর্ধ্ব সীমার উপরে গেলে স্বয়ংক্রিয় অ্যালার্ট লগ রেকর্ড

## 6. ফাইন্যান্স ম্যানেজমেন্ট

### 6.1 AR/AP
- ক্রয় রিসিভ/সেলস ডেলিভারি থেকে স্বয়ংক্রিয় তৈরি
- স্ট্যাটাস: রাইট-অফ হয়নি → আংশিক রাইট-অফ → রাইট-অফ সম্পন্ন
- একই সোর্স ডকুমেন্টে আইডেমপোটেন্ট প্রোটেকশন

### 6.2 রসিদ ম্যানেজমেন্ট
- মাল্টি-অ্যাকাউন্ট (নগদ/ব্যাংক/WeChat/Alipay)
- রিভিউর পর অ্যাকাউন্ট ব্যালেন্স ও ক্যাশ জার্নাল স্বয়ংক্রিয় আপডেট
- AR রেকর্ড রাইট-অফ সাপোর্ট

### 6.3 পেমেন্ট ম্যানেজমেন্ট
- রসিদের মতোই লজিক, দিক বিপরীত
- AP রেকর্ড রাইট-অফ সাপোর্ট

### 6.4 ক্যাশ ও ব্যাংক জার্নাল
- অ্যাকাউন্ট+তারিখ অনুযায়ী ইনকাম/এক্সপেন্ড ফ্লো রেকর্ড
- ব্যাংক অ্যাকাউন্ট ব্যালেন্স রিয়েল-টাইম আপডেট

### 6.5 খরচ রিইমবার্সমেন্ট
- প্রক্রিয়া: সাবমিট → অনুমোদন → পেমেন্ট
- পেমেন্টের পর স্বয়ংক্রিয় পেমেন্ট ফর্ম + জার্নাল তৈরি

### 6.6 লাভ-লস স্টেটমেন্ট
- মাস অনুযায়ী সামারি: অপারেটিং ইনকাম, অপারেটিং কস্ট, খরচ, মুনাফা
- স্ন্যাপশট স্টোরেজ (year+month ইউনিক)

### 6.7 স্থায়ী সম্পদ
- সম্পদের পূর্ণ লাইফসাইকেল: ক্রয় → ব্যবহার → অবচয় → নিষ্পত্তি
- স্ট্রেইট-লাইন অবচয়: (মূল্য-আনুমানিক অবশিষ্ট) / ব্যবহারের মাস সংখ্যা
- মাসিক অবচয় গণনা, স্বয়ংক্রিয় অবচয় রেকর্ড তৈরি
- রেকর্ড: মূল্য, অবশিষ্ট মূল্য, ব্যবহারের বছর, মাসিক অবচয় অঙ্ক, সঞ্চিত অবচয়, নেট ভ্যালু

### 6.8 ট্যাক্স ম্যানেজমেন্ট
- মাল্টি-ট্যাক্স: ভ্যাট/কর্পোরেট ইনকাম ট্যাক্স/ব্যক্তিগত ইনকাম ট্যাক্স/স্ট্যাম্প ডিউটি
- ট্যাক্স রেট নমনীয় কনফিগারেশন (৪টি ডিফল্ট ট্যাক্স রেট সিড ডেটাসহ)
- ক্রয়/বিক্রয় ডকুমেন্টের সাথে লিংক, স্বয়ংক্রিয় ট্যাক্স অঙ্ক রেকর্ড

### 6.9 মাল্টি-কারেন্সি
- কারেন্সি ম্যানেজমেন্ট: CNY/USD/EUR/JPY (৪টি ডিফল্ট কারেন্সি সিড ডেটাসহ)
- হোম কারেন্সি আইডেন্টিফায়ার
- এক্সচেঞ্জ রেট কার্যকর তারিখ অনুযায়ী ম্যানেজমেন্ট

### 6.10 বাজেট ম্যানেজমেন্ট
- বার্ষিক বাজেট প্রণয়ন: কস্ট সেন্টার + অ্যাকাউন্ট + মাস অনুযায়ী
- বাজেট vs প্রকৃত তুলনামূলক বিশ্লেষণ (এক্সিকিউশন রেট + পার্থক্য)
- স্ট্যাটাস: ড্রাফ্ট → অনুমোদিত → চলমান → বন্ধ

### 6.11 কস্ট সেন্টার/প্রফিট সেন্টার
- ট্রি লেভেল স্ট্রাকচার
- কস্ট সংগ্রহ + খরচ বণ্টন
- প্রফিট সেন্টার স্বাধীন অ্যাকাউন্টিং

- অংশগ্রহণকারী কাস্টমার ট্র্যাকিং, কনভার্সন রেট স্ট্যাটিসটিক্স

### 7.4 সার্ভিস টিকেট

## 10. প্রজেক্ট ম্যানেজমেন্ট

- প্রায়োরিটি: নিম্ন/মধ্যম/উচ্চ/জরুরি
- প্রজেক্ট বাজেট vs প্রকৃত কস্ট তুলনা
- টাস্ক প্রগ্রেস স্বয়ংক্রিয়ভাবে প্রজেক্ট প্রগ্রেসে একত্রিত হয়
- কাস্টমার লিংক, প্রজেক্ট ম্যানেজার নিয়োগ

### 10.2 WBS টাস্ক ডিকম্পোজিশন
- ট্রি টাস্ক স্ট্রাকচার (প্যারেন্ট-চাইল্ড টাস্ক সীমাহীন স্তর)
- গ্যান্ট চার্ট ডেটা সাপোর্ট (টাস্ক ডিপেন্ডেন্সি, টাইমলাইন)
- টাস্ক স্ট্যাটাস: শুরু না হওয়া → চলমান → সম্পন্ন → বিলম্বিত
- আনুমানিক কাজের সময় vs প্রকৃত কাজের সময়

### 10.3 টাইমশিট রেকর্ড
- প্রজেক্ট/টাস্ক/ব্যক্তি/তারিখ অনুযায়ী কাজের সময় রেকর্ড
- টাস্কের প্রকৃত কাজের সময় স্বয়ংক্রিয় সামারি
- প্রজেক্ট কস্ট অ্যাকাউন্টিং সাপোর্ট

## 11. হিউম্যান রিসোর্স ম্যানেজমেন্ট

### 11.2 অ্যাটেনডেন্স ম্যানেজমেন্ট
- অ্যাটেনডেন্স রুল: কাজের শুরু/শেষ সময়, দেরি গ্রেস, আগে চলে যাওয়ার গ্রেস

- লিভ ম্যানেজমেন্ট: বার্ষিক ছুটি/ব্যক্তিগত ছুটি/অসুস্থ ছুটি/বিয়ে/মাতৃত্ব/সময়-অফ

### 11.3 বেতন ম্যানেজমেন্ট
- বেতন আইটেম কনফিগারেশন: ইনকাম আইটেম/ডিডাকশন আইটেম, ট্যাক্সেবল কিনা, ডিফল্ট অঙ্ক
- বেতন গণনা: বেস স্যালারি + পারফরম্যান্স + ওভারটাইম - ডিডাকশন - পার্সোনাল ট্যাক্স = নিট প্রদেয়
- ব্যাচ মাসিক বেতন জেনারেশন সাপোর্ট
- বেতন প্রদান নিশ্চিতকরণ

## 12. উৎপাদন ও ম্যানুফ্যাকচারিং

### 12.1 BOM বিল অফ ম্যাটেরিয়াল
- পণ্য BOM: ফিনিশড গুড → কম্পোনেন্ট → কাঁচামাল, মাল্টি-লেভেল ট্রি স্ট্রাকচার
- ভার্সন ম্যানেজমেন্ট: ড্রাফ্ট → কার্যকর → অকার্যকর
- কম্পোনেন্ট বিস্তারিত: ব্যবহারের পরিমাণ, ইউনিট, ক্ষতি রেট

### 12.2 উৎপাদন ওয়ার্ক অর্ডার
- BOM-এর ভিত্তিতে উৎপাদন ওয়ার্ক অর্ডার তৈরি
- স্ট্যাটাস: উৎপাদন অপেক্ষমাণ → উৎপাদনে → সম্পন্ন → বাতিল
- প্ল্যান আউটপুট vs প্রকৃত আউটপুট
- প্ল্যান শুরু/শেষ তারিখ vs প্রকৃত শুরু/শেষ সময়

### 12.3 প্রসেস রাউটিং
- পণ্য অনুযায়ী প্রসেস ফ্লো সংজ্ঞা
- প্রতিটি প্রসেস ওয়ার্কস্টেশন, স্ট্যান্ডার্ড কাজের সময়ের সাথে লিংকড
- প্রসেস সর্টিং

### 12.4 ওয়ার্কস্টেশন
- ওয়ার্কস্টেশন কোড, নাম, ক্যাপাসিটি (প্রতি ঘণ্টা)
- সক্রিয়/নিষ্ক্রিয়

### 12.5 MRP ম্যাটেরিয়াল রিকোয়ারমেন্ট প্ল্যানিং
- নেট ডিমান্ড হিসাব: মোট ডিমান্ড - প্ল্যানড রিসিভ - বর্তমান স্টক = নেট ডিমান্ড
- পিরিয়ড (বছর+মাস) অনুযায়ী প্ল্যান তৈরি
- স্ট্যাটাস: ড্রাফ্ট → জেনারেটেড → নিশ্চিত

## 16. অর্ডার ম্যানেজমেন্ট (OMS)

### 16.1 অর্ডার ম্যানেজমেন্ট
- **মাল্টি-চ্যানেল অর্ডার ইমপোর্ট**: manual/web/mobile/api/marketplace/edi/pos সাপোর্ট
- **অর্ডার এক্সটেনশন তথ্য**: চ্যানেল অর্ডার নম্বর, স্টোর, ফুলফিলমেন্ট স্ট্যাটাস, পেমেন্ট স্ট্যাটাস, প্রায়োরিটি
- **ইনভেন্টরি অ্যালোকেশন**: ATP (আমাউন্ট টু প্রমিজ) হিসাব → ইনভেন্টরি রিজার্ভেশন (পেসিমিস্টিক লক দিয়ে ওভারসেল প্রতিরোধ)
- **ফুলফিলমেন্ট অর্কেস্ট্রেশন**: অ্যালোকেশন → ফুলফিলমেন্ট তৈরি → WMS-এ পাঠানো → পিকিং/প্যাকিং → TMS শিপমেন্ট
- **অর্ডার ক্যান্সেলেশন**: ইনভেন্টরি রিজার্ভেশন স্বয়ংক্রিয় রিলিজ

### 16.2 RMA রিটার্ন-এক্সচেঞ্জ
- RMA তৈরি (রিটার্ন/এক্সচেঞ্জ/মেরামত) → অনুমোদন → ফেরত → রিসিভ-স্টক-ইন (stockIn) → রিফান্ড
- রিটার্ন শিপিং ফি, রিফান্ড অঙ্ক ম্যানেজমেন্ট সাপোর্ট

### 16.3 চ্যানেল ম্যানেজমেন্ট
- চ্যানেল কোড/নাম/টাইপ (direct/marketplace/edi/pos)
- চ্যানেল কনফিগারেশন (JSON), সক্রিয়/নিষ্ক্রিয় স্ট্যাটাস

## 17. গুদাম ম্যানেজমেন্ট (WMS)

### 17.1 জোন ও লোকেশন
- **জোন**: রিসিভিং জোন/স্টোরেজ জোন/পিকিং জোন/প্যাকিং জোন/শিপিং জোন/রিটার্ন জোন/QC জোন
- **লোকেশন এক্সটেনশন**: আইল → শেলফ → লেভেল → পজিশন লেয়ার + বারকোড/ভলিউম/ওজন ক্যাপাসিটি/পিকিং অর্ডার

### 17.2 ইনবাউন্ড প্রসেস
- **ASN (অ্যাডভান্স শিপিং নোটিস)**: সাপ্লায়ার → প্রত্যাশিত আগমন → ক্যারিয়ার → ট্র্যাকিং নম্বর
- **রিসিভিং টাস্ক**: ডকে রিসিভ → প্রকৃত পরিমাণ এন্ট্রি → QC
- **পুটঅ্যাওয়ে টাস্ক**: স্বয়ংক্রিয় তৈরি → অ্যাসাইন → স্ট্র্যাটেজি (fifo/zone_fixed/abc) → পুটঅ্যাওয়ে নিশ্চিতকরণ (stockIn)

### 17.3 আউটবাউন্ড প্রসেস
- **ওয়েভ ম্যানেজমেন্ট**: মাল্টি-অর্ডার অ্যাগ্রিগেশন → পিকিং ওয়েভ/শিপিং ওয়েভ → প্রায়োরিটি
- **পিকিং টাস্ক**: সিঙ্গেল/ব্যাচ/জোন/ওয়েভ পিকিং → অ্যাসাইন → নিশ্চিতকরণ (প্রকৃত পিকড পরিমাণ)
- **প্যাকিং টাস্ক**: প্যাকেজ টাইপ (box/bag/pallet) → ওজন/মাত্রা

## 18. পরিবহন ম্যানেজমেন্ট (TMS)

### 18.1 ক্যারিয়ার
- ক্যারিয়ার কোড/টাইপ (এক্সপ্রেস/LTL/FTL/এয়ার/সি/রেল)
- ক্যারিয়ার সার্ভিস: standard/express/overnight/2day/economy + লিড টাইম
- API কনফিগারেশন: custom/shippo/afterShip/17track অ্যাবস্ট্রাকশন

### 18.2 ফ্রেট ম্যানেজমেন্ট
- **রেট কার্ড**: অরিজিন/ডেস্টিনেশন → ওয়েট ব্যান্ড → বেস ফি/প্রতি কেজি ফি/ফুয়েল সারচার্জ
- **মাল্টি-কারেন্সি**: CNY/USD/EUR ইত্যাদি, exchange_rate-এর সাথে লিংকড
- **ফ্রেট কম্পারিজন**: গন্তব্য দেশ+ওজন অনুযায়ী সব উপলব্ধ রেট কোয়েরি, অ্যাসেন্ডিং অর্ডারে

### 18.3 শিপমেন্ট ও ট্র্যাকিং
- **শিপমেন্ট**: ক্যারিয়ার সার্ভিস → ট্র্যাকিং নম্বর → স্ট্যাটাস (শিপমেন্ট অপেক্ষমাণ → পিকআপ → ট্রানজিটে → ডেলিভারড/এক্সসেপশন/রিটার্নড)
- **লজিস্টিক ট্র্যাকিং**: webhook কলব্যাক → শিপমেন্ট স্ট্যাটাস স্বয়ংক্রিয় সিঙ্ক
- **ফ্রেট ইনভয়েস**: তৈরি → নিশ্চিতকরণ → পেমেন্ট → AP তৈরি
