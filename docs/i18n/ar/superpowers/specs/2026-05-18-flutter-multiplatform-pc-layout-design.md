# تخطيط متعدد المنصات بأسلوب PC في Flutter — مواصفات التصميم

التاريخ: 2026-05-18

## الهدف

تفعيل منصتي سطح المكتب macOS وWindows، وضمان استخدام جميع المنصات (iOS (iPhone + iPad) وmacOS وWindows وLinux) لتخطيط لوحة إدارة بأسلوب PC (شريط جانبي + شريط علوي + منطقة محتوى)، مع تكيف الهواتف عبر قائمة الدرج (Drawer).

## استراتيجية المنصات

| المنصة | الحالة | الوصف |
|------|------|------|
| Linux | مفعلة | لا حاجة لإجراء |
| macOS | يتطلب التفعيل | `flutter config --enable-macos-desktop` |
| Windows | يتطلب التفعيل | `flutter config --enable-windows-desktop` |
| iOS | موجودة | تغطي iPhone (تخطيط الهاتف) وiPad (تخطيط سطح المكتب) |
| Web | موجودة | لا حاجة لإجراء |

لا يوجد هدف منصة مستقل لـ iPad، ويحقق تخطيط سطح المكتب عبر إصابة نقطة توقف TABLET بالتصميم المتجاوب.

## نقاط التوقف المتجاوبة

| نقطة التوقف | النطاق | نمط التخطيط |
|------|------|----------|
| PHONE | 0 - 767 | قائمة الدرج (AppBar + Drawer) |
| TABLET | 768 - 1199 | شريط جانبي قابل للطي (مطوي افتراضيًا 64px) |
| DESKTOP | 1200 - 2460 | شريط جانبي (ممتد افتراضيًا 240px) |

أصغر عرض لشاشة iPad العمودية 768px، فيصيب TABLET ويحصل على تخطيط الشريط الجانبي.
عروض iPhone كلها أقل من 768px، فتصيب PHONE وتحصل على قائمة الدرج.

## تغييرات الملفات

### 1. main.dart — إعداد نقاط التوقف

- `PHONE`: 0-767, `TABLET`: 768-1199, `DESKTOP`: 1200-2460
- باقي الكود دون تغيير

### 2. admin_layout.dart — تبديل التنقل المتجاوب

- `_isPhone`: إصابة نقطة توقف PHONE
- `_buildPhoneLayout()`: Scaffold + AppBar + Drawer، وDrawer الداخلي يعيد استخدام نفس عناصر القائمة مع NavigationDrawer لسطح المكتب
- `_buildDesktopLayout()`: تخطيط Row الحالي (شريط جانبي + شريط علوي + منطقة محتوى)
- في TABLET يُطوى الشريط الجانبي افتراضيًا، وفي DESKTOP يُمد افتراضيًا

### 3. app_theme.dart — استكمال السمة الداكنة

- استخراج أنماط المكونات كثوابت خاصة `_dataTableTheme` و`_cardTheme` و`_inputDecorationTheme` و`_dividerTheme`
- إعادة استخدام السمتين الفاتحة والداكنة لنفس مجموعة أنماط المكونات
- استكمال السمة الداكنة باستخدام Material 3 + نفس seed + سطوع dark
