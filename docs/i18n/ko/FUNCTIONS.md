## 1. 시스템 관리

### 1.1 사용자 관리
- 관리자 계정 전 생애주기 관리(생성/수정/삭제/활성·비활성)
- 일괄 작업: 일괄 삭제, 일괄 활성화/비활성화
- Excel 일괄 사용자 가져오기, 행별 검증 + 오류 보고서
- 비밀번호 bcrypt 해시 저장, 비밀번호 변경 시 기존 비밀번호 확인 필요
- 삭제 등 민감 작업은 현재 사용자 비밀번호 2차 확인 필요
- 휴대폰/이메일/주민등록번호 암호화 저장, 목록 자동 마스킹

### 1.2 역할 권한 (RBAC)
- 역할 관리: 생성/수정/삭제, slug 고유 식별자
- 권한 트리: 무한 레벨 트리 구조, 3가지 유형 — 메뉴(내비게이션 표시), 버튼(페이지 내 작업), API(인터페이스 접근)
- 권한 식별자 형식: `{method}.{path}`, 예: `get.admin/product`, `post.admin/user/batch/destroy`
- 역할-권한 다대다 연관, 슈퍼 관리자는 모든 권한 검사 생략
- AdminPermission 미들웨어 Redis 사용자 권한 캐시(TTL=60s)

### 1.3 시스템 설정
- 키-값 저장, 그룹 관리 지원
- 값 유형: 문자열/정수/불리언/JSON/배열

### 1.4 작업 감사
- 모든 POST/PUT/DELETE 작업 자동 기록
- 작업자, 동작, 메서드, 경로, IP, 파라미터(민감 필드 마스킹), 시간 기록
- 8개 플랫폼 출처 단말 자동 감지(Web/Flutter/HarmonyOS/API 등)
- 읽기 전용 조회, 삭제하거나 수정할 수 없음

### 1.5 보안 방어
- 7계층 심층 방어: HTTP 메서드 제한, XSS/SQL 인젝션/경로 탐색/명령 인젝션/CSRF 차단
- 클릭 캡차(로그인/가입 필수 검증)
- Redis 슬라이딩 윈도우 속도 제한(Lua 원자화, 기본 60회/분)
- 계정 잠금: 5회 실패 시 15분 잠금
- 동시 세션 제한: 동일 사용자 최대 3개 유효 Token
- CSP 헤더, security.txt (RFC 9116)
- 민감 작업 무작위 2차 검증(poster-php)

## 2. 상품과 기초 데이터

### 2.1 상품 관리
- 상품 마스터: 코드(고유), 이름, 바코드, 규격, 기본 단위, 이미지, 설명
- 다중 규격 SKU: 동일 상품 아래 여러 SKU, 각각 독립 코드·바코드·규격 속성(JSON)
- 다중 단위 환산: 기본 단위와 보조 단위 환산율
- 가격 정책: 매입가, 도매가, 소매가, 고객 등급별 가격
- ES 전문 검색 지원

### 2.2 상품 분류
- 무한 레벨 트리 분류 구조
- 정렬, 활성화/비활성화 지원
- 드래그 정렬

### 2.3 브랜드 관리
- 브랜드 이름, Logo, 설명, 정렬

### 2.4 창고·로케이션
- 다중 창고 관리(이름, 코드, 주소, 담당자, 연락처)
- 각 창고에 다중 로케이션(코드는 창고 내에서 고유)

### 2.5 공급업체 관리
- 공급업체 코드, 이름, 담당자, 전화/이메일(암호화), 주소
- 은행 계좌 정보(암호화 저장), 사업자등록번호, 세율
- ES 전문 검색

### 2.6 고객 관리
- 고객 코드, 이름, 고객 등급, 신용 한도
- 담당자/전화/이메일(암호화)/주소
- 고객 등급: 이름, 기본 할인율
- ES 전문 검색

## 3. 구매 관리

### 3.1 구매 신청
- 부서/담당자가 구매 수요 제출
- 승인 프로세스: 승인 대기 → 승인/반려 → 주문 전환
- 승인 워크플로 엔진 연동 가능

### 3.2 구매 오더
- 공급업체 연관, 상품 내역(수량, 단가, 금액)
- 상태: 심사 대기 → 심사 완료 → 부분 입고 → 입고 완료 → 취소
- 신청 기반 생성 가능, 직접 생성도 가능

### 3.3 구매 입고(모듈 간 연동)
- 오더 기준 입고, 분할 지원
- 입고 자동 트리거: ① 입고(이동가중평균 원가 계산) ② 매입채무 기록 생성 ③ 오더 입고 수량 갱신

### 3.4 구매 반품
- 공급업체로 반품, 출고 상쇄 생성

### 3.5 공급업체 정산
- 공급업체별 집계: 구매 금액, 지급 완료, 미지급
- 상태: 미정산/부분 정산/정산 완료

## 5. 재고 관리

### 5.1 실시간 재고
- 4차원 정밀도: 창고 + 로케이션 + 로트 + SKU
- 다중 창고, 다중 로케이션 지원
- 실시간 재고 조회

### 5.2 입출고 이력
- 모든 재고 변동 일괄 기록(방향, 수량, 원가, 출처 오더번호, 시간)

### 5.3 로트 추적
- 생산일자, 만료일자, 로트번호
- 입출고 시 로트 기록

### 5.4 시리얼 번호 추적
- 고유 시리얼 번호 관리
- 입출고 시 상태 기록(재고/출고)

### 5.5 원가 계산
- 이동가중평균법
- 공식: 새 평균가 = (기존 재고 총액 + 이번 입고 총액) / (기존 재고 수량 + 이번 입고 수량)
- 입고 시마다 자동 재계산, 출고는 현재 평균가로 원가 처리

### 5.6 재고 이동
- 창고 간/로케이션 간 이동
- 상태: 이동 대기 → 이동 완료(출) → 이동 완료(입) → 완료
- 이동 출/입 이력 자동 생성

### 5.7 재고 실사
- 계획 실사(창고/분류 기준) + 동적 실사(SKU 기준)
- 장부 수량 vs 실사 수량 기록
- 차이로 자동으로 재고 과부족 이력 생성

### 5.8 재고 경고
- SKU+창고별 상한/하한 설정
- 하한 미만/상한 초과 시 자동으로 경고 로그 기록

### 5.9 로트/시리얼 번호 추적과 유효기간 경고(v1.4.0 전달)

- 추적 체인: TraceService forward/backward가 로트의 행선지/출처를 정·역방향으로 추적하고, serial은 시리얼 번호 대장
- 유효기간 경고: expiryAlert가 유효기간 임박 및 경과 로트를 알림

## 6. 재무 관리

### 6.1 매출채권·매입채무
- 구매 입고/판매 출고로 자동 생성
- 상태: 미정산 → 부분 정산 → 정산 완료
- 동일 출처 문서 이중성(멱등성) 보호

### 6.2 수금 관리
- 다중 계좌(현금/은행/위챗/알리페이)
- 심사 후 자동으로 계좌 잔액과 현금 일계부 갱신
- 매출채권 기록 정산 지원

### 6.3 지급 관리
- 수금과 동일 로직, 방향만 반대
- 매입채무 기록 정산 지원

### 6.4 현금·은행 일계부
- 계좌+일자별 수입/지출 이력 기록
- 은행 계좌 잔액 실시간 갱신

### 6.5 비용 정산
- 프로세스: 제출 → 승인 → 송금
- 송금 후 자동으로 지급 전표 + 일계부 생성

### 6.6 손익계산서
- 월별 집계: 영업 수익, 영업 비용, 비용, 이익
- 스냅샷 저장(year+month 고유)

### 6.7 고정자산
- 자산 전 생애주기: 취득 → 사용 → 감가상각 → 처분
- 정액법 감가상각: (원가-잔존가치) / 사용 개월 수
- 월별 감가상각 계상, 자동으로 감가상각 기록 생성
- 기록: 원가, 잔존가치, 사용 연한, 월 감가상각액, 누적 감가상각, 장부가액

### 6.8 세무 관리
- 다중 세목: 부가가치세/법인세/개인소득세/인지세
- 세율 유연 구성(기본 세율 시드 4개 포함)
- 구매/판매 문서와 연동, 세액 자동 기록

### 6.9 다중 통화
- 통화 관리: CNY/USD/EUR/JPY(기본 통화 시드 4개 포함)
- 기능 통화 표시
- 환율은 적용 일자 기준 관리

### 6.10 예산 관리
- 연간 예산 편성: 원가센터 + 계정과목 + 월 단위
- 예산 vs 실적 비교 분석(실행률 + 차이)
- 상태: 초안 → 승인 완료 → 실행 중 → 마감

### 6.11 원가센터/이익센터
- 트리 계층 구조
- 원가 귀속 + 비용 배분
- 이익센터 독립 회계

### 6.12 기말 이월 / 다중 조직 회계 / 재무제표 연결(v1.4.0 전달)

- 기말 손익 이월: 기간별로 손익 계정 발생액 집계(수익 - 비용 = 순이익, status=calculated)

## 7. CRM

### 7.1 고객 관리
- 고객 마스터(기초 데이터 고객과 연관)
- 다중 담당자 관리(대표 담당자 표시)

### 7.2 팔로우 기록
- 팔로우 방식: 전화/방문/이메일/메시지/기타

### 7.3 마케팅 활동
- 활동 전 생애주기: 계획 → 진행 중 → 완료 → 취소

## 모듈 간 데이터 흐름

```
采购收货 → 自动入库(移动加权平均成本) → 生成应付记录
销售发货 → 自动出库 → 生成应收记录
收付款 → 核销应收应付 → 更新日记账
盘点差异 → 自动生成盈亏出入库流水
审批提交 → 工作流引擎路由 → 逐级审批 → 通知推送
费用报销打款 → 自动生成付款单 + 日记账
资产折旧 → 按月计提 → 成本分摊到成本中心
MRP 运算 → BOM 展开 → 净需求计算 → 生成采购/生产建议
请假审批 → 通过后更新考勤状态
生产完工 → 自动入库(产成品) + 扣减原材料库存
工时记录 → 汇总到任务 → 聚合到项目成本
```
