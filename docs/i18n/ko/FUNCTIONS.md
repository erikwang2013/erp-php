## 개요

오픈ERP 시스템(open-erp)은 19개 업무 도메인 <!-- stats:modules=19 -->, 163개 데이터 테이블 <!-- stats:tables=163 -->을 포괄하며, 매입·판매·재고부터 생산 제조, 재무 회계부터 인사 관리까지의 풀스택 기업 관리 시스템을 제공합니다. 국제화: 중문/English 이중 언어 지원, Accept-Language 요청 헤더로 자동 전환됩니다.

> API 문서: 서비스 시작 후 `http://localhost:8787/apidoc`에 접속하면 인터랙티브 인터페이스 문서를 볼 수 있습니다(hg/apidoc 자동 생성)

## 1. 시스템 관리

### 1.1 사용자 관리
- 관리자 계정 전 생애주기 관리(생성/수정/삭제/활성·비활성)
- 일괄 작업: 일괄 삭제, 일괄 활성화/비활성화
- Excel 일괄 사용자 가져오기, 행별 검증 + 오류 보고서
- 비밀번호 bcrypt 해시 저장, 비밀번호 변경 시 기존 비밀번호 확인 필요
- 삭제 등 민감 작업은 현재 사용자 비밀번호 2차 확인 필요
- 휴대폰/이메일/주민등록번호 암호화 저장, 목록 자동 마스킹

### 1.2 역할 권한 (RBAC)
- 역할 관리: 생성/수정/삭제, slug 고유 식별자
- 권한 트리: 무한 레벨 트리 구조, 3가지 유형 — 메뉴(내비게이션 표시), 버튼(페이지 내 작업), API(인터페이스 접근)
- 권한 식별자 형식: `{method}.{path}`, 예: `get.admin/product`, `post.admin/user/batch/destroy`
- 역할-권한 다대다 연관, 슈퍼 관리자는 모든 권한 검사 생략
- AdminPermission 미들웨어 Redis 사용자 권한 캐시(TTL=60s)

### 1.3 시스템 설정
- 키-값 저장, 그룹 관리 지원
- 값 유형: 문자열/정수/불리언/JSON/배열

### 1.4 작업 감사
- 모든 POST/PUT/DELETE 작업 자동 기록
- 작업자, 동작, 메서드, 경로, IP, 파라미터(민감 필드 마스킹), 시간 기록
- 8개 플랫폼 출처 단말 자동 감지(Web/Flutter/HarmonyOS/API 등)
- 읽기 전용 조회, 삭제하거나 수정할 수 없음

### 1.5 보안 방어
- 18계층 심층 방어: HTTP 메서드 제한, XSS/SQL 인젝션/경로 탐색/명령 인젝션/CSRF 차단
- 클릭 캡차(로그인/가입 필수 검증)
- Redis 슬라이딩 윈도우 속도 제한(Lua 원자화, 기본 60회/분)
- 계정 잠금: 5회 실패 시 15분 잠금
- 동시 세션 제한: 동일 사용자 최대 3개 유효 Token
- CSP 헤더, security.txt (RFC 9116)
- 민감 작업 무작위 2차 검증(poster-php)

## 2. 상품과 기초 데이터

### 2.1 상품 관리
- 상품 마스터: 코드(고유), 이름, 바코드, 규격, 기본 단위, 이미지, 설명
- 다중 규격 SKU: 동일 상품 아래 여러 SKU, 각각 독립 코드·바코드·규격 속성(JSON)
- 다중 단위 환산: 기본 단위와 보조 단위 환산율
- 가격 정책: 매입가, 도매가, 소매가, 고객 등급별 가격
- ES 전문 검색 지원

### 2.2 상품 분류
- 무한 레벨 트리 분류 구조
- 정렬, 활성화/비활성화 지원
- 드래그 정렬

### 2.3 브랜드 관리
- 브랜드 이름, Logo, 설명, 정렬

### 2.4 창고·로케이션
- 다중 창고 관리(이름, 코드, 주소, 담당자, 연락처)
- 각 창고에 다중 로케이션(코드는 창고 내에서 고유)

### 2.5 공급업체 관리
- 공급업체 코드, 이름, 담당자, 전화/이메일(암호화), 주소
- 은행 계좌 정보(암호화 저장), 사업자등록번호, 세율
- ES 전문 검색

### 2.6 고객 관리
- 고객 코드, 이름, 고객 등급, 신용 한도
- 담당자/전화/이메일(암호화)/주소
- 고객 등급: 이름, 기본 할인율
- ES 전문 검색

## 3. 구매 관리

### 3.1 구매 신청
- 부서/담당자가 구매 수요 제출
- 승인 프로세스: 승인 대기 → 승인/반려 → 주문 전환
- 승인 워크플로 엔진 연동 가능

### 3.2 구매 오더
- 공급업체 연관, 상품 내역(수량, 단가, 금액)
- 상태: 심사 대기 → 심사 완료 → 부분 입고 → 입고 완료 → 취소
- 신청 기반 생성 가능, 직접 생성도 가능

### 3.3 구매 입고(모듈 간 연동)
- 오더 기준 입고, 분할 지원
- 입고 자동 트리거: ① 입고(이동가중평균 원가 계산) ② 매입채무 기록 생성 ③ 오더 입고 수량 갱신

### 3.4 구매 반품
- 공급업체로 반품, 출고 상쇄 생성

### 3.5 공급업체 정산
- 공급업체별 집계: 구매 금액, 지급 완료, 미지급
- 상태: 미정산/부분 정산/정산 완료

## 4. 판매 관리

### 4.1 견적서
- 고객에게 견적, 판매 오더 전환 지원
- 상태: 초안 → 견적 완료 → 오더 전환 → 기간 만료

### 4.2 판매 오더
- 고객 연관, 상품 내역(수량, 단가, 할인)
- 상태: 심사 대기 → 심사 완료 → 부분 출고 → 출고 완료 → 취소

### 4.3 판매 출고(모듈 간 연동)
- 오더 기준 출고, 분할 지원
- 출고 자동 트리거: ① 출고(이동가중평균 원가 기준) ② 매출채권 기록 생성 ③ 오더 출고 수량 갱신

### 4.4 판매 반품
- 고객 반품, 입고 상쇄 생성

### 4.5 고객 정산과 매출이익
- 고객별 집계: 판매 금액, 수금 완료, 미수금
- 오더/상품/고객 차원의 매출이익 계산

## 5. 재고 관리

### 5.1 실시간 재고
- 4차원 정밀도: 창고 + 로케이션 + 로트 + SKU
- 다중 창고, 다중 로케이션 지원
- 실시간 재고 조회

### 5.2 입출고 이력
- 모든 재고 변동 일괄 기록(방향, 수량, 원가, 출처 오더번호, 시간)

### 5.3 로트 추적
- 생산일자, 만료일자, 로트번호
- 입출고 시 로트 기록

### 5.4 시리얼 번호 추적
- 고유 시리얼 번호 관리
- 입출고 시 상태 기록(재고/출고)

### 5.5 원가 계산
- 이동가중평균법
- 공식: 새 평균가 = (기존 재고 총액 + 이번 입고 총액) / (기존 재고 수량 + 이번 입고 수량)
- 입고 시마다 자동 재계산, 출고는 현재 평균가로 원가 처리

### 5.6 재고 이동
- 창고 간/로케이션 간 이동
- 상태: 이동 대기 → 이동 완료(출) → 이동 완료(입) → 완료
- 이동 출/입 이력 자동 생성

### 5.7 재고 실사
- 계획 실사(창고/분류 기준) + 동적 실사(SKU 기준)
- 장부 수량 vs 실사 수량 기록
- 차이로 자동으로 재고 과부족 이력 생성

### 5.8 재고 경고
- SKU+창고별 상한/하한 설정
- 하한 미만/상한 초과 시 자동으로 경고 로그 기록

## 6. 재무 관리

### 6.1 매출채권·매입채무
- 구매 입고/판매 출고로 자동 생성
- 상태: 미정산 → 부분 정산 → 정산 완료
- 동일 출처 문서 이중성(멱등성) 보호

### 6.2 수금 관리
- 다중 계좌(현금/은행/위챗/알리페이)
- 심사 후 자동으로 계좌 잔액과 현금 일계부 갱신
- 매출채권 기록 정산 지원

### 6.3 지급 관리
- 수금과 동일 로직, 방향만 반대
- 매입채무 기록 정산 지원

### 6.4 현금·은행 일계부
- 계좌+일자별 수입/지출 이력 기록
- 은행 계좌 잔액 실시간 갱신

### 6.5 비용 정산
- 프로세스: 제출 → 승인 → 송금
- 송금 후 자동으로 지급 전표 + 일계부 생성

### 6.6 손익계산서
- 월별 집계: 영업 수익, 영업 비용, 비용, 이익
- 스냅샷 저장(year+month 고유)

### 6.7 고정자산
- 자산 전 생애주기: 취득 → 사용 → 감가상각 → 처분
- 정액법 감가상각: (원가-잔존가치) / 사용 개월 수
- 월별 감가상각 계상, 자동으로 감가상각 기록 생성
- 기록: 원가, 잔존가치, 사용 연한, 월 감가상각액, 누적 감가상각, 장부가액

### 6.8 세무 관리
- 다중 세목: 부가가치세/법인세/개인소득세/인지세
- 세율 유연 구성(기본 세율 시드 4개 포함)
- 구매/판매 문서와 연동, 세액 자동 기록

### 6.9 다중 통화
- 통화 관리: CNY/USD/EUR/JPY(기본 통화 시드 4개 포함)
- 기능 통화 표시
- 환율은 적용 일자 기준 관리

### 6.10 예산 관리
- 연간 예산 편성: 원가센터 + 계정과목 + 월 단위
- 예산 vs 실적 비교 분석(실행률 + 차이)
- 상태: 초안 → 승인 완료 → 실행 중 → 마감

### 6.11 원가센터/이익센터
- 트리 계층 구조
- 원가 귀속 + 비용 배분
- 이익센터 독립 회계

## 7. CRM

### 7.1 고객 관리
- 고객 마스터(기초 데이터 고객과 연관)
- 다중 담당자 관리(대표 담당자 표시)
- 담당자 전화/이메일 암호화 저장

### 7.2 팔로우 기록
- 팔로우 방식: 전화/방문/이메일/메시지/기타
- 팔로우 내용, 다음 팔로우 계획, 다음 팔로우 시간 기록
- 고객, 담당자 연관

### 7.3 마케팅 활동
- 활동 전 생애주기: 계획 → 진행 중 → 완료 → 취소
- 다중 채널: 이메일/문자/전화/이벤트/소셜 미디어
- 참여 고객 추적, 전환율 통계
- 예산 vs 실제 지출 비교

### 7.4 서비스 티켓
- 티켓 관리: 대기 → 처리 중 → 해결 → 마감
- 우선순위: 낮음/보통/높음/긴급
- 분류: 기술 지원/불만/문의/반품·교환/기타
- 처리자 배정 + 답글(공개/내부 메모)

### 7.5 고객 분석 리포트
- 6대 핵심 지표: 신규 고객/활성 고객/유지율/객단가/CLV/티켓 해결률
- 리포트 자동 생성(JSON 데이터 스냅샷)
- 월간/분기/연간 지원

## 8. 승인 워크플로 엔진

### 8.2 승인 작업
- 제출 → 단계별 승인 → 통과/반려/회수
- 내 승인 목록(승인 대기 + 승인 완료)
- 승인 기록 완전 추적

## 10. 프로젝트 관리

### 10.1 프로젝트
- 프로젝트 전 생애주기: 계획 중 → 진행 중 → 연기 → 완료 → 취소
- 우선순위: 낮음/보통/높음/긴급
- 프로젝트 예산 vs 실제 원가 비교
- 태스크 진도 자동 집계로 프로젝트 진도 산출
- 고객 연관, 프로젝트 매니저 배정

### 10.2 WBS 태스크 분해
- 트리 태스크 구조(상하위 태스크 무한 레벨)
- 간트 차트 데이터 지원(태스크 의존성, 타임라인)
- 태스크 상태: 시작 대기 → 진행 중 → 완료 → 연기
- 예상 공수 vs 실제 공수

### 10.3 공수 기록
- 프로젝트/태스크/인원/일자별 공수 기록
- 태스크 실제 공수 자동 집계
- 프로젝트 원가 계산 지원

- 직원 마스터: 코드, 이름, 성별, 생년월일, 입사일, 상태
- 민감 필드 암호화: 휴대폰, 이메일, 주민등록번호, 은행 계좌

### 11.2 근태 관리
- 근태 규칙: 출퇴근 시간, 지각 유예, 조퇴 유예
- 출퇴근 기록: 출근/퇴근 체크, 지각/조퇴 분 자동 계산
- 상태: 정상/지각/조퇴/결근/휴가/출장

### 11.3 급여 관리
- 급여 항목 구성: 수입 항목/공제 항목, 과세 여부, 기본 금액
- 급여 계산: 기본급 + 성과급 + 연장근무 - 공제 - 개인소득세 = 실지급
- 월간 급여 일괄 생성 지원
- 급여 지급 확인

- **로케이션 확장**: 통로 → 랙 → 층 → 로케이션 계층 + 바코드/용적/하중/피킹 순서

- **상하차 태스크**: 자동 생성 → 배정 → 전략(fifo/zone_fixed/abc) → 상하차 확정(stockIn)

### 17.3 출고 프로세스
- **웨이브 관리**: 다중 오더 집계 → 피킹 웨이브/출고 웨이브 → 우선순위
- **피킹 태스크**: 오더별/일괄/구역/웨이브 피킹 → 배정 → 확정(실피킹 수량)

## 18. 운송 관리 (TMS)

### 18.1 운송사
- 운송사 코드/유형(택배/소량/전차량/항공/해운/철도)
- 운송사 서비스: standard/express/overnight/2day/economy + 처리 시간
- API 구성: custom/shippo/afterShip/17track 추상화

### 18.2 운임 관리
- **요율 카드**: 출발지/목적지 → 중량 구간 → 기본 요금/kg당 요금/유류 할증료
- **다중 통화**: CNY/USD/EUR 등, exchange_rate 연동
- **운임 비교**: 목적 국가 + 중량으로 모든 유효 요율 조회, 오름차순 정렬

### 18.3 운송장과 물류 이력
- **운송장**: 운송사 서비스 → 추적번호 → 상태(출고 대기 → 수거 완료 → 운송 중 → 배송 완료/이상/반송)
- **물류 이력**: webhook 콜백 → 운송장 상태 자동 동기화
- **운임 인보이스**: 생성 → 확정 → 지급 → AP 생성
