## v1.17.0 変更（2026-09-15）

> 版の位置づけは変わりません：リポジトリは依然として完全版（Full）の 1 セットのみを実装し、Lite/Standard 列は製品計画値で、対応ブランチはアーカイブ凍結済みです。

- **管理画面が 2 セットから 3 セットへ**：Angular 22（`apps/angular/`）と React 19 + Vite（`apps/react/`）が加わり、
  既存の Flutter 3.x Web（`apps/flutter/`）と並び、3 端が同一の `/admin/v1`、`/api/v1`、`/open/v1` インターフェースを共用します。
- **全プラットフォーム 13 語種**（zh/en/ja/ko/de/fr/es/pt/ru/ar/hi/bn/id）：
  - バックエンドのレスポンスメッセージ `resource/translations/<locale>/`——`zh_CN` 565 条、残り 11 語種は各 544 条、`en` 30 条
    （口径：3 ファイルのリーフ項目で、`validation.php` の `attributes` フィールドラベルは算入、そのグループキーは不算入——`zh_CN` は 21 個のフィールドラベルを訳出したため 21 条多くなっています。`en` 行は「英語すなわち key」で、辞書はほぼ空です）
  - 管理画面 UI：Angular ソース辞書 1456 キー、React 1451 キー × 11 新語種；**語種ごとに遅延読み込み**、各語種が 1 つの chunk になります
  - 生成器：`scripts/gen-be-locales.mjs`（バックエンド）、`scripts/gen-fe-locales.mjs`（フロントエンド、`--app angular|react`）
  - 切替入口：トップバーの**独立した globe アイコン** + 個人センターのドロップダウン（両端で統一）
- **Flutter と HarmonyOS は引き続き中/英の 2 語種**で、今回は対象外です。
- **下表への影響**：Full 列は 163 表 / 122 コントローラー / 19 業務モジュール → **227 / 159 / 23**；
  完成度マトリクスに「多言語 (i18n)」行を追加（モジュール行 44 → 45、バックエンド API 39 → 40、業務ロジック 33 → 34）；
  なお 2026-09-15 に重複していた「マルチテナント」行を統合した結果、モジュール行は 44 に戻りました（バックエンド API 39、業務ロジック 33）。
  上記は v1.17.0 当時の増分口径であり、そのまま保持します。

## ブランチ戦略（2026-08-27 より）

> `lite` / `standard` / `full` の 3 つの版ブランチに適用され、CI release ジョブ（冪等な版 tag）と一致します。
> **現状の補足（2026-09-22 実測）**：3 ブランチは削除済みです。本節の残りの項目は「アーカイブ＝コミットと tag」として理解してください。
> checkout できる版ブランチはもう存在しません。

- **`main` は唯一の開発源**：すべての機能開発、欠陥修正、依存関係アップグレードは一律に `main` へマージし、コミットは Lead が一括実行します。
- **版ブランチはアーカイブのみで、維持しません**：`lite` / `standard` / `full` は歴史的アーカイブブランチとして凍結され、新規コミットを受け付けず、
  `main` の増分も同期せず、強制更新や push も行いません（3 本のコードラインを維持しないため）；**凍結期間の終了後、3 ブランチは削除済み**で、
  アーカイブ内容は `main` の履歴 `eea90c0` に残っています。
- **版の差異は版 tag で記録**：リリースは CI release ジョブが最新 tag から冪等に `vX.Y.Z` を作成します
  （`scripts/bump-version.sh` を参照）；各版の機能差異は tag および上記の機能比較表を基準とし、ブランチのコードラインを維持するものではありません。
- **検証**：`main` の CI がそのままリリース検証であり、アーカイブブランチは個別に CI を実行しません。（2026-09-15 以降、release ジョブの依存は `docs` + `e2e`；php ジョブは実行されますがリリースはブロックしません——その赤は CI 専用の統合テストの歴史的負債で、`.github/workflows/ci.yml` のコメントを参照。）
