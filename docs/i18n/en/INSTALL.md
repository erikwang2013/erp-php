## Installation Steps

### 1. Create the Database

```sql
CREATE DATABASE `erp` DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'erp'@'localhost' IDENTIFIED BY '你的密码';
GRANT ALL PRIVILEGES ON `erp`.* TO 'erp'@'localhost';
FLUSH PRIVILEGES;
```

### 2. Import the Database (one command)

```bash
cd /home/wwwroot/erp-php/service
mysql -u root -p erp < database/install.sql
```

`install.sql` contains the structures of all 227 tables and the initial seed data (super admin role, permission tree, funnel stages, tax rates, currencies, analytics metrics, document categories, service endpoint permissions); the schema uses database/install.sql as its single source of truth.

### 3. Configure Environment Variables

```bash
cd /home/wwwroot/erp-php/service
cp .env.example .env
```

Edit `.env` and modify the following key configuration:

```ini
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=erp
DB_USERNAME=erp
DB_PASSWORD=你的密码
DB_PREFIX=erp_

REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=

JWT_SECRET_KEY=修改为32位以上随机字符串
APP_KEY=修改为32位随机字符串

# 开放注册开关（默认 0=关闭，接口返回 403；生产建议保持关闭）
REGISTRATION_ENABLED=0
```

### 4. Install PHP Dependencies

```bash
cd /home/wwwroot/erp-php/service
composer install --no-dev --optimize-autoloader
```

### 5. Start the Service

```bash
php start.php start
```

Listens on `http://0.0.0.0:8788` by default.

### 6. Verify the Installation

```bash
curl http://localhost:8788/health
```

Visit `http://localhost:8788/apidoc` in your browser to view the API documentation.

## Upgrading a Deployed Environment

This repository ships no migration tooling: the schema and seed data use `database/install.sql` as their single source of truth, and that file is a **one-shot full-database install script
(plain `INSERT`, not idempotent) — it must not be re-run against a live database**. Upgrades are performed by hand from the diff:

```bash
git diff <old-version>..<new-version> -- database/install.sql    # extract the table-structure and seed differences
```

1. Run the `CREATE TABLE` (they carry `IF NOT EXISTS`, so they can be run as-is) / `ALTER TABLE` / seed `INSERT` statements from the diff against the live database, in order.
2. **Permission seeds**: the `erp_admin_permission` rows corresponding to new endpoints must be added. The super admin is the exception — it holds a wildcard permission
   (the "all permissions" row in `erp_admin_permission` with `slug = '*'`; `app/middleware/AdminPermission.php:38`
   grants everything on seeing `*`), so new endpoints take effect automatically; custom roles need the association added as well:

   ```sql
   INSERT INTO `erp_admin_role_permission` (`role_id`, `permission_id`)
   SELECT <role ID>, `id` FROM `erp_admin_permission` WHERE `slug` = '<permission slug of the new endpoint>';
   ```

3. After upgrading, run `curl http://localhost:8788/health` and an admin login smoke test once to confirm the service is usable.

## Initial Account

After installation, a super admin role (`super_admin`) with all permissions is pre-seeded. The first use requires manually creating an admin account:

```sql
-- 创建管理员（密码使用 bcrypt 哈希）
INSERT INTO `erp_admin_user` (`id`, `username`, `password`, `real_name`, `status`)
VALUES (90000000000000001, 'admin', '$2y$10$...', '系统管理员', 1);

-- 关联超级管理员角色
INSERT INTO `erp_admin_user_role` (`user_id`, `role_id`)
VALUES (90000000000000001, 10000000000000001);
```

> `id` is generated at the application layer by `snowflake-php`, or can be obtained through the registration endpoint.

## Docker Compose Deployment

The project root orchestrates 5 services: `nginx`, `app` (PHP 8.3), `mysql` (8.0), `redis` (7), `elasticsearch` (8.x).

```bash
cd /home/wwwroot/erp-php
cp .env.docker .env
# Replace placeholder keys with random values (idempotent)
bash scripts/gen-env-keys.sh .env
docker-compose up -d

# 进入容器导入数据库
docker-compose exec app bash
mysql -h mysql -u root -p erp < database/install.sql
```

## Database Conventions

| Convention | Description |
|------|------|
| Table prefix | `erp_` |
| Primary key | `id` BIGINT UNSIGNED NOT NULL, non-auto-increment, generated by snowflake-php |
| Charset | utf8mb4, utf8mb4_unicode_ci |
| Engine | InnoDB |
| Soft delete | `deleted_at` DATETIME DEFAULT NULL |
| Timestamps | `created_at` / `updated_at` maintained automatically |
| Sensitive fields | encrypted/decrypted automatically via the encryptable trait |

## Troubleshooting

### Database Connection Failure
```bash
systemctl status mysql
cat service/.env | grep DB_
```

### Redis Connection Failure
```bash
redis-cli ping    # 应返回 PONG
```

### Port Already in Use
```bash
ss -tlnp | grep 8788
# 修改监听端口: config/server.php
```

### File Permissions
```bash
chmod -R 755 service/runtime
chown -R www-data:www-data service/runtime
```
