## Overview

The Open ERP System (open-erp) covers 19 business domains <!-- stats:modules=19 --> with 163 data tables <!-- stats:tables=163 -->, providing a full-stack enterprise management system from purchasing/sales/inventory to production manufacturing, from financial accounting to human resources. ## 1. System Management

### 1.1 User Management
- Full lifecycle management of administrator accounts (create/edit/delete/enable-disable)
- Batch operations: batch delete, batch enable/disable
- Excel batch import of users, per-row validation + error report
- Passwords stored as bcrypt hashes; changing a password requires confirming the original password
- Sensitive operations such as delete require a second confirmation with the current user's password
- Phone/email/ID number stored encrypted, list views auto-masked

### 1.2 Roles & Permissions (RBAC)
- Role management: create/edit/delete, slug unique identifier
- Permission tree: unlimited-level tree structure, three types — menu (navigation visibility), button (in-page actions), API (endpoint access)
- Permission identifier format: `{method}.{path}`, e.g. `get.admin/product`, `post.admin/user/batch/destroy`
- Role-permission many-to-many association; super admin skips all permission checks
- AdminPermission middleware caches user permissions in Redis (TTL=60s)

### 1.3 System Config
- Key-value storage, group management supported
- Value types: string/integer/boolean/JSON/array

### 1.4 Operation Audit
- Automatically records all POST/PUT/DELETE operations
- Records operator, action, method, path, IP, parameters (sensitive fields masked), time
- Auto-detects 8 platform sources (Web/Flutter/HarmonyOS/API, etc.)
- Read-only queries; cannot be deleted or modified

### 1.5 Security Protection
- 18-layer defense in depth: HTTP method restriction, XSS/SQL injection/path traversal/command injection/CSRF blocking
- Click captcha (mandatory check on login/registration)
- Redis sliding-window rate limiting (Lua atomic, default 60 times/minute)
- Account lockout: 5 failed attempts locks for 15 minutes
- Concurrent session limit: at most 3 valid Tokens per user
- CSP headers, security.txt (RFC 9116)
- Random second verification for sensitive operations (poster-php)

## 2. Products & Master Data

### 2.1 Product Management
- Product records: code (unique), name, barcode, specification, base unit, image, description
- Multi-spec SKUs: multiple SKUs under the same product, each with its own code, barcode, spec attributes (JSON)
- Multi-unit conversion: conversion rate between base unit and auxiliary units
- Pricing strategy: purchase price, wholesale price, retail price, customer-level price
- ES full-text search supported

### 2.2 Product Categories
- Unlimited-level tree category structure
- Sorting and enable/disable supported
- Drag-and-drop sorting

### 2.3 Brand Management
- Brand name, logo, description, sort order

### 2.4 Warehouses & Locations
- Multi-warehouse management (name, code, address, manager, contact phone)
- Multiple locations per warehouse (code unique within a warehouse)

### 2.5 Supplier Management
- Supplier code, name, contact person, phone/email (encrypted), address
- Bank account info (stored encrypted), tax ID, tax rate
- ES full-text search

### 2.6 Customer Management
- Customer code, name, customer level, credit limit
- Contact person/phone/email (encrypted)/address
- Customer level: name, default discount rate
- ES full-text search

## 3. Purchase Management

### 3.1 Purchase Requisition
- Departments/people submit purchase requirements
- Approval flow: pending approval → approved/rejected → converted to order
- Can be wired into the approval workflow engine

### 3.2 Purchase Orders
- Linked to supplier, item lines (quantity, unit price, amount)
- Status: pending review → reviewed → partially received → received → cancelled
- Can be created from a requisition or directly

### 3.3 Purchase Receiving (cross-module linkage)
- Receive against the order, partial receiving supported
- Receiving auto-triggers: ① stock-in (moving weighted average costing) ② AP record generation ③ order received-quantity update

### 3.4 Purchase Returns
- Return to supplier, generates stock-out reversal

### 3.5 Supplier Settlement
- Aggregated per supplier: purchase amount, paid, payable
- Status: unsettled/partially settled/settled

## 4. Sales Management

### 4.1 Quotations
- Quote to customer, convertible to sales order
- Status: draft → quoted → converted to order → expired

### 4.2 Sales Orders
- Linked to customer, item lines (quantity, unit price, discount)
- Status: pending review → reviewed → partially shipped → shipped → cancelled

### 4.3 Sales Delivery (cross-module linkage)
- Ship against the order, partial shipment supported
- Shipping auto-triggers: ① stock-out (at moving weighted average cost) ② AR record generation ③ order shipped-quantity update

### 4.4 Sales Returns
- Customer returns, generates stock-in reversal

### 4.5 Customer Settlement & Gross Margin
- Aggregated per customer: sales amount, received, receivable
- Gross margin computed by order/item/customer dimension

## 5. Inventory Management

### 5.1 Live Inventory
- Four-dimension precision: warehouse + location + batch + SKU
- Multi-warehouse, multi-location supported
- Live inventory query

### 5.2 Stock In/Out Flows
- All inventory changes recorded uniformly (direction, quantity, cost price, source document number, time)

### 5.3 Batch Tracking
- Production date, expiry date, batch number
- Batch recorded on stock in/out

### 5.4 Serial Number Tracking
- Unique serial number management
- Status recorded on stock in/out (in stock/out)

### 5.5 Costing
- Moving weighted average method
- Formula: new average = (original total stock value + incoming total value) / (original stock quantity + incoming quantity)
- Auto-recalculated on each stock-in; stock-outs costed at the current average

### 5.6 Inventory Transfers
- Transfers between warehouses/locations
- Status: pending transfer → transferred out → transferred in → completed
- Transfer-out/in flows auto-generated

### 5.7 Stock Counts
- Planned counts (by warehouse/category) + dynamic counts (by SKU)
- Records book vs. actual quantities
- Differences auto-generate count gain/loss flows

### 5.8 Inventory Alerts
- Min/max limits per SKU+warehouse
- Auto-records alert logs when below min/above max

## 6. Finance Management

### 6.1 AR/AP
- Auto-generated by purchase receiving/sales delivery
- Status: unreconciled → partially reconciled → reconciled
- Idempotency protection per source document

### 6.2 Receipt Management
- Multiple accounts (cash/bank/WeChat/Alipay)
- Auto-updates account balance and cash journal after review
- AR reconciliation supported

### 6.3 Payment Management
- Same logic as receipts, opposite direction
- AP reconciliation supported

### 6.4 Cash & Bank Journals
- Income/expense flows recorded per account+date
- Bank account balance updated in real time

### 6.5 Expense Reimbursement
- Flow: submit → approve → pay out
- Auto-generates payment voucher + journal entry after pay-out

### 6.6 Income Statement
- Monthly aggregation: operating revenue, operating cost, expenses, profit
- Snapshot storage (year+month unique)

### 6.7 Fixed Assets
- Full asset lifecycle: acquisition → usage → depreciation → disposal
- Straight-line depreciation: (original value - residual value) / months of useful life
- Monthly depreciation accrual, depreciation records auto-generated
- Records: original value, residual value, useful life in years, monthly depreciation, accumulated depreciation, net book value

### 6.8 Tax Management
- Multiple tax types: VAT/corporate income tax/personal income tax/stamp duty
- Tax rates flexibly configurable (4 default tax rate seed records included)
- Linked to purchase/sales documents, tax amounts auto-recorded

### 6.9 Multi-Currency
- Currency management: CNY/USD/EUR/JPY (4 default currency seed records included)
- Base currency flag
- Exchange rates managed by effective date

### 6.10 Budget Management
- Annual budget planning: by cost center + account + month
- Budget vs. actual comparison analysis (execution rate + variance)
- Status: draft → approved → in execution → closed

### 6.11 Cost Center / Profit Center
- Tree hierarchy structure
- Cost collection + expense allocation
- Profit centers account independently

## Cross-Module Data Flow

```
采购收货 → 自动入库(移动加权平均成本) → 生成应付记录
销售发货 → 自动出库 → 生成应收记录
收付款 → 核销应收应付 → 更新日记账
盘点差异 → 自动生成盈亏出入库流水
审批提交 → 工作流引擎路由 → 逐级审批 → 通知推送
费用报销打款 → 自动生成付款单 + 日记账
资产折旧 → 按月计提 → 成本分摊到成本中心
MRP 运算 → BOM 展开 → 净需求计算 → 生成采购/生产建议
请假审批 → 通过后更新考勤状态
生产完工 → 自动入库(产成品) + 扣减原材料库存
工时记录 → 汇总到任务 → 聚合到项目成本
```

## 16. Order Management (OMS)

### 16.1 Order Management
- **Multi-channel order import**: manual/web/mobile/api/marketplace/edi/pos supported
- **Order extended info**: channel order number, store, fulfillment status, payment status, priority
- **Inventory allocation**: ATP (Available To Promise) calculation → inventory reservation (pessimistic lock against overselling)
- **Fulfillment orchestration**: allocation → fulfillment creation → dispatch to WMS → picking/packing → TMS shipment
- **Order cancellation**: auto-releases inventory reservations

### 16.2 RMA Returns & Exchanges
- RMA creation (return/exchange/repair) → approval → return → receiving stock-in (stockIn) → refund
- Return shipping cost and refund amount management supported

### 16.3 Channel Management
- Channel code/name/type (direct/marketplace/edi/pos)
- Channel config (JSON), enable/disable status

---

## 17. Warehouse Management (WMS)

### 17.1 Zones & Locations
- **Zones**: receiving/storage/picking/packing/shipping/return/QC
- **Location extension**: aisle → rack → level → slot hierarchy + barcode/volume/weight capacity/pick order

### 17.2 Inbound Flow
- **ASN (Advanced Shipping Notice)**: supplier → expected arrival → carrier → tracking number
- **Receiving task**: dock receiving → actual quantity entry → QC
- **Putaway task**: auto-generated → assigned → strategy (fifo/zone_fixed/abc) → putaway confirmation (stockIn)

### 17.3 Outbound Flow
- **Wave management**: multi-order aggregation → picking wave/shipping wave → priority
- **Pick task**: order/batch/zone/wave picking → assigned → confirmation (actual picked quantity)
- **Pack task**: packing types (box/bag/pallet) → weight/dimensions

---

## 18. Transportation Management (TMS)

### 18.1 Carriers
- Carrier code/type (express/LTL/FTL/air/sea/rail)
- Carrier services: standard/express/overnight/2day/economy + transit times
- API config: custom/shippo/afterShip/17track abstraction

### 18.2 Freight Management
- **Rate cards**: origin/destination → weight band → base fee/per-kg fee/fuel surcharge
- **Multi-currency**: CNY/USD/EUR etc., linked to exchange_rate
- **Freight rate comparison**: query all available rates by destination country + weight, sorted ascending

### 18.3 Shipments & Tracking
- **Shipments**: carrier service → tracking number → status (pending shipment → picked up → in transit → delivered/exception/returned)
- **Tracking events**: webhook callbacks → auto-sync shipment status
- **Freight invoices**: create → confirm → pay → AP generation
