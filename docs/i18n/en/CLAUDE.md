## Tech Stack

### Backend
- PHP 8.3+, webman v2 (workerman/webman)
- Database: MySQL 8.0+, table prefix `erp_`
- Primary keys: BIGINT non-auto-increment, generated by `erikwang2013/snowflake-php`
- API-layer ID encryption: `erikwang2013/hashids`
- JWT authentication: `erikwang2013/jwt-webman`
- API sensitive data encryption: `erikwang2013/encryption`
- Database sensitive field encryption: `erikwang2013/encryptable`
- ES sync and query: `erikwang2013/webman-scout`
- Country flags: `erikwang2013/season`
- API doc generation: `erikwang2013/apidoc-php` | annotation-based, visit /apidoc

### Frontend
- Flutter 3.x, source directory `apps/flutter/`
- Web is designed in PC admin console style (not mobile app style)
- Supports both client and administrator ends
- HarmonyOS ArkTS, source directory `apps/harmonyos/`
- Angular 22 CLI + ng-zorro-antd, source directory `apps/angular/` (web admin console)
- React 19 + Vite, source directory `apps/react/` (web admin console)
- All four frontends share one backend: Angular / React use `/admin/v1`, `/api/v1`, `/open/v1` just like Flutter, with each dev server proxying to webman during development

### Internationalization (13 Languages)
- Language list: `zh_CN` `en` `ja` `ko` `de` `fr` `es` `pt` `ru` `ar` `hi` `bn` `id`
- Backend dictionaries: `resource/translations/<locale>/{common,modules,validation}.php`, 13 locale directories; `zh_CN` 565 entries, each of the other 11 locales 544 entries, `en` 30 entries (scope: leaf entries across the three files; the `attributes` field labels in `validation.php` count, their group keys do not)
  - "English is the key": `en`'s common/modules are left empty; the keys in `validation.php` are framework rule names, so only the values are translated
  - Generator: `scripts/gen-be-locales.mjs`
- Frontend dictionary (Angular): source `apps/angular/src/app/core/zh-en/part1..4.ts` (1456 entries) → artifacts `apps/angular/src/app/core/zh-<code>.ts`
- Frontend dictionary (React): source `apps/react/src/lib/i18n/zhEn.ts` (1451 entries) → artifacts `apps/react/src/lib/i18n/zh<Code>.ts`
  - Each of the 11 new locale dictionaries is dynamically `import()`ed into its own chunk; missing entries fall back to the original Chinese text
  - Generator: `scripts/gen-fe-locales.mjs --app angular|react`
- Runtime: switching language switches the `Accept-Language` request header, and the backend returns text per locale (`app/common/I18n.php` + `config/translation.php`)

## Middleware Execution Chain

```
全局:  Cors → SecurityFilter(方法检查→405) → RateLimit → TracingId → {路由中间件}
/health:  Cors → SecurityFilter(方法检查→405) → RateLimit → TracingId → Controller
/install: Cors → SecurityFilter(方法检查→405) → RateLimit → TracingId → Controller
/admin/v1:   Cors → SecurityFilter(方法检查→405) → RateLimit → TracingId → AdminAuth → AdminPermission → OperationLog → Controller
/api/v1:     Cors → SecurityFilter(方法检查→405) → RateLimit → TracingId → Controller
/open/v1:    Cors → SecurityFilter(方法检查→405) → RateLimit → TracingId → OpenApiAuth → Controller
```

## Security Hardening

- **HTTP method restriction**: SecurityFilter only allows GET/POST/PUT/DELETE/OPTIONS/HEAD; non-standard methods return 405
- **CSP headers**: Content-Security-Policy + X-Permitted-Cross-Domain-Policies injected into all responses
- **Account lockout**: 5 consecutive failed logins lock the account for 15 minutes
- **Concurrent session limit**: at most 3 valid Tokens per user; the oldest Token is blacklisted when exceeded
- **security.txt**: `/.well-known/security.txt` RFC 9116 endpoint
- **Nginx security config**: `nginx-security.conf` reverse-proxy security hardening reference

## API Version Strategy

Versions live in the URL path (`/admin/v1`, `/api/v1`, `/open/v1`); there is no version request header:

```bash
curl http://localhost:8788/api/v1/auth/login
```

Adding a version only requires creating the `app/api/{version}/controller/` directory and registering the `/api/v{version}` group in `config/route.php` (the version appears in the URL path only, controllers are bound directly, and there is no version-header middleware — the former `ApiVersion` header middleware has been removed).

## Rate Limiting Strategy

Redis sliding window (Lua atomic), default 60 times/minute/IP/route:
- Login: 10 times/minute
- Registration: 5 times/minute
- Response headers: `X-RateLimit-Limit/Remaining/Reset`, plus `Retry-After` when over limit

## Code Standards

### PHP
- No leading `\` for global functions/class references; use `use` imports
- Config files must include Chinese comments explaining the meaning of each config item
- All new `.php` files must start with the copyright notice

### Database
- Table prefix: `erp_`
- Primary key `id`: BIGINT type, non-auto-increment, generated by snowflake
- Sensitive fields auto-encrypt/decrypt via the `erikwang2013/encryptable` trait
- schema uses database/install.sql as its single source of truth (single-file SQL)

### Flutter
- Web layout uses PC admin console style (sidebar + top bar + content area)
- GetX state management, `ApiService` singleton (Dio + JWT interceptor)
- Token persistence via `shared_preferences`
- Responsive breakpoints: mobile (< 768px) and desktop (>= 768px)

### HarmonyOS
- Native HTTP client via `@ohos.net.http`
- Token silent refresh: auto-calls `/api/v1/auth/refresh` on 401
- Refresh failure auto-redirects to the login page

## Deployment

### Docker Compose (recommended for production)

The project root `docker-compose.yml` orchestrates 5 services:

| Service | Description |
|------|------|
| `nginx` | Nginx reverse proxy (80/443), static file serving |
| `app` | webman PHP 8.3 app, built via `Dockerfile` (with OPcache + event + redis) |
| `mysql` | MySQL 8.0, data volume persistence |
| `redis` | Redis 7 Alpine, cache/rate limiting/sessions |
| `elasticsearch` | Elasticsearch 8.x, full-text search |

```bash
cp .env.docker .env
docker-compose up -d
```

### CI/CD

`.github/workflows/ci.yml` defines the GitHub Actions pipeline (PHP 8.2/8.3/8.4 matrix):

- PHP syntax check (`php -l`)
- PHPStan static analysis (`vendor/bin/phpstan analyse`)
- PHP CS Fixer style check (`vendor/bin/php-cs-fixer fix --dry-run --diff`)
- PHPUnit unit tests
- Composer security audit (`composer audit --no-dev`)

### Database Backup

`database/backup/backup.sh` — mysqldump + gzip, auto-cleans backups older than 30 days.
`database/backup/restore.sh` — interactive restore, lists available backups to choose from.

### Monitoring

The `GET /metrics` endpoint (`MetricsController`) outputs Prometheus text format with 5 gauge metrics:
- `openadmin_http_requests_total` — total request count
- `openadmin_active_users` — active user count
- `openadmin_db_connection_status` — database connection status (0/1)
- `openadmin_redis_connection_status` — Redis connection status (0/1)
- `openadmin_memory_usage_bytes` — memory usage
