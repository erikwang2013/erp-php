# Flutter मल्टी-प्लेटफ़ॉर्म PC शैली लेआउट — डिज़ाइन विनिर्देश

दिनांक: 2026-05-18

## लक्ष्य

macOS, Windows डेस्कटॉप प्लेटफ़ॉर्म सक्षम करें, सुनिश्चित करें कि iOS (iPhone + iPad), macOS, Windows, Linux सभी प्लेटफ़ॉर्म PC प्रशासन बैकएंड शैली लेआउट (साइडबार + टॉपबार + सामग्री क्षेत्र) का उपयोग करें, मोबाइल एंड पर ड्रॉअर मेनू से अनुकूलित करें।

## प्लेटफ़ॉर्म रणनीति

| प्लेटफ़ॉर्म | स्थिति | विवरण |
|------|------|------|
| Linux | सक्षम | कोई कार्रवाई आवश्यक नहीं |
| macOS | सक्षम करना होगा | `flutter config --enable-macos-desktop` |
| Windows | सक्षम करना होगा | `flutter config --enable-windows-desktop` |
| iOS | पहले से मौजूद | iPhone (फ़ोन लेआउट) और iPad (डेस्कटॉप लेआउट) दोनों कवर करता है |
| Web | पहले से मौजूद | कोई कार्रवाई आवश्यक नहीं |

iPad का कोई स्वतंत्र प्लेटफ़ॉर्म लक्ष्य नहीं है, रिस्पॉन्सिव ब्रेकपॉइंट के TABLET स्तर पर पहुँचकर डेस्कटॉप लेआउट प्राप्त होता है।

## रिस्पॉन्सिव ब्रेकपॉइंट

| ब्रेकपॉइंट | दायरा | लेआउट मोड |
|------|------|----------|
| PHONE | 0 - 767 | ड्रॉअर मेनू (AppBar + Drawer) |
| TABLET | 768 - 1199 | कोलेप्सेबल साइडबार (डिफ़ॉल्ट संक्षिप्त 64px) |
| DESKTOP | 1200 - 2460 | साइडबार (डिफ़ॉल्ट विस्तारित 240px) |

iPad पोर्ट्रेट न्यूनतम चौड़ाई 768px, TABLET पर पहुँचकर साइडबार लेआउट प्राप्त करता है।
iPhone की चौड़ाई सभी 768px से कम, PHONE पर पहुँचकर ड्रॉअर मेनू प्राप्त करता है।

## फ़ाइल परिवर्तन

### 1. main.dart — ब्रेकपॉइंट कॉन्फ़िगरेशन

- `PHONE`: 0-767, `TABLET`: 768-1199, `DESKTOP`: 1200-2460
- शेष कोड अपरिवर्तित

### 2. admin_layout.dart — रिस्पॉन्सिव नेविगेशन स्विचिंग

- `_isPhone`: PHONE ब्रेकपॉइंट पर पहुँचता है
- `_buildPhoneLayout()`: Scaffold + AppBar + Drawer, Drawer के अंदर NavigationDrawer डेस्कटॉप साइडबार के समान मेनू आइटम पुन: उपयोग करता है
- `_buildDesktopLayout()`: मौजूदा Row लेआउट (साइडबार + टॉपबार + सामग्री क्षेत्र)
- TABLET पर साइडबार डिफ़ॉल्ट रूप से संक्षिप्त, DESKTOP पर डिफ़ॉल्ट रूप से विस्तारित

### 3. app_theme.dart — डार्क थीम पूर्ति

- घटक शैलियाँ निजी स्थिरांक `_dataTableTheme`, `_cardTheme`, `_inputDecorationTheme`, `_dividerTheme` में निकालें
- लाइट और डार्क थीम समान घटक शैलियाँ पुन: उपयोग करती हैं
- डार्क थीम Material 3 + समान seed + dark ब्राइटनेस का उपयोग करती है
