## Технологический стек

### Бэкенд
- PHP 8.3+, webman v2 (workerman/webman)
- База данных: MySQL 8.0+, префикс таблиц `erik_`
- Первичный ключ: BIGINT без автоинкремента, генерируется `erikwang2013/snowflake-php`
- Шифрование/дешифрование ID на уровне API: `erikwang2013/hashids`
- JWT-аутентификация: `erikwang2013/jwt-webman`
- Шифрование чувствительных данных API: `erikwang2013/encryption`
- Шифрование чувствительных полей БД: `erikwang2013/encryptable`
- Синхронизация и поиск ES: `erikwang2013/webman-scout`
- Флаги стран: `erikwang2013/season`
- Генерация документации API: `hg/apidoc` | аннотационный подход, доступ по /apidoc

### Фронтенд
- Flutter 3.x, исходники в каталоге `apps/flutter/`
- Web-версия спроектирована в стиле PC-панели управления (не в стиле мобильного приложения)
- Поддержка клиентской и административной части
- HarmonyOS ArkTS, исходники в каталоге `apps/harmonyos/`

## Цепочка выполнения middleware

```
Глобально: Locale → Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → {middleware маршрута}
/health:  Locale → Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → Controller
/install: Locale → Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → Controller
/admin:   Locale → Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → AdminAuth → AdminPermission → OperationLog → Controller
/api:     Locale → Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → ApiVersion → Controller
```

## Усиление безопасности

- **Ограничение HTTP-методов**: SecurityFilter допускает только GET/POST/PUT/DELETE/OPTIONS/HEAD, нестандартные методы возвращают 405
- **Заголовок CSP**: Content-Security-Policy + X-Permitted-Cross-Domain-Policies внедряются во все ответы
- **Блокировка аккаунта**: 5 неудачных входов подряд — блокировка аккаунта на 15 минут
- **Ограничение параллельных сессий**: у одного пользователя максимум 3 действующих Token, при превышении самый старый Token попадает в чёрный список
- **security.txt**: эндпоинт `/.well-known/security.txt` по RFC 9116
- **Конфигурация безопасности Nginx**: `docs/nginx-security.conf` — эталон усиления обратного прокси

## Стратегия версий API

Версия задаётся заголовком запроса `API-Version` (по умолчанию `v1`), в URL не отражается:

```bash
curl -H "API-Version: v1" http://localhost:8787/api/auth/login
```

Для новой версии достаточно создать каталог `app/api/{version}/controller/` и зарегистрировать его в middleware `ApiVersion`.

## Политика лимита запросов

Скользящее окно Redis (атомарно на Lua), по умолчанию 60 раз/мин/IP/маршрут:
- Вход: 10 раз/мин
- Регистрация: 5 раз/мин
- Заголовки ответа: `X-RateLimit-Limit/Remaining/Reset`, при превышении дополнительно `Retry-After`

## Стандарты кода

### PHP
- Глобальные функции/классы без префикса `\`, импорт через `use`
- Файлы конфигурации должны содержать комментарии на китайском с пояснением каждого параметра
- Все новые файлы `.php` должны начинаться с заявления об авторских правах

### База данных
- Префикс таблиц: `erik_`
- Первичный ключ `id`: BIGINT, без автоинкремента, генерируется snowflake
- Чувствительные поля шифруются/дешифруются автоматически через trait `erikwang2013/encryptable`
- schema: единственный источник истины — database/install.sql (один файл SQL)

### Flutter
- Web-версия использует стиль PC-панели управления (боковая панель + верхняя панель + область содержимого)
- Управление состоянием GetX, синглтон `ApiService` (Dio + JWT-перехватчик)
- Хранение token через `shared_preferences`
- Адаптивные точки перелома: мобильный (< 768px) и десктоп (>= 768px)

### HarmonyOS
- Нативный HTTP-клиент `@ohos.net.http`
- Бесшовное обновление token: при 401 автоматический вызов `/api/auth/refresh`
- При неудачном обновлении — автоматический редирект на страницу входа

## Развёртывание

| Сервис | Описание |
|------|------|


### Резервное копирование базы данных

`database/backup/backup.sh` — mysqldump + gzip, автоматическая очистка бэкапов старше 30 дней.
`database/backup/restore.sh` — интерактивное восстановление, показывает доступные бэкапы для выбора.

### Мониторинг

Эндпоинт `GET /metrics` (MetricsController) выводит формат Prometheus text, 5 метрик gauge:
- `openadmin_http_requests_total` — общее количество запросов
- `openadmin_active_users` — количество активных пользователей
- `openadmin_db_connection_status` — статус подключения к БД (0/1)
- `openadmin_redis_connection_status` — статус подключения к Redis (0/1)
- `openadmin_memory_usage_bytes` — объём используемой памяти
