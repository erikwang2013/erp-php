## Технологический стек

### Бэкенд
- PHP 8.3+, webman v2 (workerman/webman)
- База данных: MySQL 8.0+, префикс таблиц `erp_`
- Первичный ключ: BIGINT без автоинкремента, генерируется `erikwang2013/snowflake-php`
- Шифрование/дешифрование ID на уровне API: `erikwang2013/hashids`
- JWT-аутентификация: `erikwang2013/jwt-webman`
- Шифрование чувствительных данных API: `erikwang2013/encryption`
- Шифрование чувствительных полей БД: `erikwang2013/encryptable`
- Синхронизация и поиск ES: `erikwang2013/webman-scout`
- Флаги стран: `erikwang2013/season`
- Генерация документации API: `erikwang2013/apidoc-php` | аннотационный подход, доступ по /apidoc

### Фронтенд
- Flutter 3.x, исходники в каталоге `apps/flutter/`
- Web-версия спроектирована в стиле PC-панели управления (не в стиле мобильного приложения)
- Поддержка клиентской и административной части
- HarmonyOS ArkTS, исходники в каталоге `apps/harmonyos/`
- Angular 22 CLI + ng-zorro-antd, исходники в каталоге `apps/angular/` (веб-панель управления)
- React 19 + Vite, исходники в каталоге `apps/react/` (веб-панель управления)
- Единый бэкенд для четырёх клиентов: Angular / React, как и Flutter, работают через `/admin/v1`, `/api/v1`, `/open/v1`; в режиме разработки каждый dev server проксирует запросы в webman

### Интернационализация (13 языков)
- Список языков: `zh_CN` `en` `ja` `ko` `de` `fr` `es` `pt` `ru` `ar` `hi` `bn` `id`
- Словари бэкенда: `resource/translations/<locale>/{common,modules,validation}.php`, 13 каталогов языков; `zh_CN` 565 записей, остальные 11 языков по 544 записи, `en` 30 записей (критерий: листовые записи трёх файлов; метки полей в `attributes` файла `validation.php` учитываются, ключи группировки — нет)
  - «Английский как ключ»: в `en` файлы common/modules пусты; ключи `validation.php` — имена правил фреймворка, переводятся только значения
  - Генератор: `scripts/gen-be-locales.mjs`
- Словарь фронтенда (Angular): источник `apps/angular/src/app/core/zh-en/part1..4.ts` (1456 записей) → артефакт `apps/angular/src/app/core/zh-<code>.ts`
- Словарь фронтенда (React): источник `apps/react/src/lib/i18n/zhEn.ts` (1451 запись) → артефакт `apps/react/src/lib/i18n/zh<Code>.ts`
  - Каждый из 11 новых словарей подгружается динамически через `import()` отдельным chunk; при отсутствии записи используется китайский оригинал
  - Генератор: `scripts/gen-fe-locales.mjs --app angular|react`
- Во время работы: переключение языка меняет заголовок запроса `Accept-Language`, бэкенд возвращает текст на соответствующем языке (`app/common/I18n.php` + `config/translation.php`)

## Цепочка выполнения middleware

```
Глобально: Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → {middleware маршрута}
/health:  Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → Controller
/install: Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → Controller
/admin/v1:   Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → AdminAuth → AdminPermission → OperationLog → Controller
/api/v1:     Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → Controller
/open/v1:    Cors → SecurityFilter(проверка методов→405) → RateLimit → TracingId → OpenApiAuth → Controller
```

## Усиление безопасности

- **Ограничение HTTP-методов**: SecurityFilter допускает только GET/POST/PUT/DELETE/OPTIONS/HEAD, нестандартные методы возвращают 405
- **Заголовок CSP**: Content-Security-Policy + X-Permitted-Cross-Domain-Policies внедряются во все ответы
- **Блокировка аккаунта**: 5 неудачных входов подряд — блокировка аккаунта на 15 минут
- **Ограничение параллельных сессий**: у одного пользователя максимум 3 действующих Token, при превышении самый старый Token попадает в чёрный список
- **security.txt**: эндпоинт `/.well-known/security.txt` по RFC 9116
- **Конфигурация безопасности Nginx**: `docs/nginx-security.conf` — эталон усиления обратного прокси

## Стратегия версий API

Версия находится в пути URL (`/admin/v1`, `/api/v1`, `/open/v1`), заголовка версии нет:

```bash
curl http://localhost:8788/api/v1/auth/login
```

Для новой версии достаточно создать каталог `app/api/{version}/controller/` и зарегистрировать группу `/api/v{version}` в `config/route.php` (номер версии отражается только в пути URL, контроллеры привязываются напрямую, middleware версии нет — прежний middleware заголовка `ApiVersion` удалён).

## Политика лимита запросов

Скользящее окно Redis (атомарно на Lua), по умолчанию 60 раз/мин/IP/маршрут:
- Вход: 10 раз/мин
- Регистрация: 5 раз/мин
- Заголовки ответа: `X-RateLimit-Limit/Remaining/Reset`, при превышении дополнительно `Retry-After`

## Стандарты кода

### PHP
- Глобальные функции/классы без префикса `\`, импорт через `use`
- Файлы конфигурации должны содержать комментарии на китайском с пояснением каждого параметра
- Все новые файлы `.php` должны начинаться с заявления об авторских правах

### База данных
- Префикс таблиц: `erp_`
- Первичный ключ `id`: BIGINT, без автоинкремента, генерируется snowflake
- Чувствительные поля шифруются/дешифруются автоматически через trait `erikwang2013/encryptable`
- schema: единственный источник истины — database/install.sql (один файл SQL)

### Flutter
- Web-версия использует стиль PC-панели управления (боковая панель + верхняя панель + область содержимого)
- Управление состоянием GetX, синглтон `ApiService` (Dio + JWT-перехватчик)
- Хранение token через `shared_preferences`
- Адаптивные точки перелома: мобильный (< 768px) и десктоп (>= 768px)

### HarmonyOS
- Нативный HTTP-клиент `@ohos.net.http`
- Бесшовное обновление token: при 401 автоматический вызов `/api/v1/auth/refresh`
- При неудачном обновлении — автоматический редирект на страницу входа

## Развёртывание

### Docker Compose (рекомендуется для продакшена)

В корне проекта `docker-compose.yml` оркестрирует 5 сервисов:

| Сервис | Описание |
|------|------|
| `nginx` | Обратный прокси Nginx (80/443), обслуживание статических файлов |
| `app` | Приложение webman на PHP 8.3, сборка через `Dockerfile` (OPcache + event + redis) |
| `mysql` | MySQL 8.0, постоянный том данных |
| `redis` | Redis 7 Alpine, кэш/лимит запросов/Session |
| `elasticsearch` | Elasticsearch 8.x, полнотекстовый поиск |

```bash
cp .env.docker .env
bash scripts/gen-env-keys.sh .env   # генерация реальных ключей (запуск с ключами-заглушками отклоняется)
docker-compose up -d
```

### CI/CD

`.github/workflows/ci.yml` определяет конвейер GitHub Actions (матрица PHP 8.2/8.3/8.4):

- Проверка синтаксиса PHP (`php -l`)
- Статический анализ PHPStan (`vendor/bin/phpstan analyse`)
- Проверка стиля кода PHP CS Fixer (`vendor/bin/php-cs-fixer fix --dry-run --diff`)
- Юнит-тесты PHPUnit
- Аудит безопасности Composer (`composer audit --no-dev`)

### Резервное копирование базы данных

`database/backup/backup.sh` — mysqldump + gzip, автоматическая очистка бэкапов старше 30 дней.
`database/backup/restore.sh` — интерактивное восстановление, показывает доступные бэкапы для выбора.

### Мониторинг

Эндпоинт `GET /metrics` (MetricsController) выводит формат Prometheus text, 5 метрик gauge:
- `openadmin_http_requests_total` — общее количество запросов
- `openadmin_active_users` — количество активных пользователей
- `openadmin_db_connection_status` — статус подключения к БД (0/1)
- `openadmin_redis_connection_status` — статус подключения к Redis (0/1)
- `openadmin_memory_usage_bytes` — объём используемой памяти
