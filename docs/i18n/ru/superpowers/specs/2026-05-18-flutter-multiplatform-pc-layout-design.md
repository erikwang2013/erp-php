# Flutter — многоплатформенный макет в стиле ПК — спецификация дизайна

Дата: 2026-05-18

## Цель

Включить настольные платформы macOS и Windows, гарантировать, что все платформы — iOS (iPhone + iPad), macOS, Windows, Linux — используют макет в стиле PC-панели управления (боковая панель + верхняя панель + область содержимого), а на телефонах применяется адаптация через ящик (Drawer).

## Стратегия платформ

| Платформа | Статус | Пояснение |
|------|------|------|
| Linux | Уже включена | Действий не требуется |
| macOS | Нужно включить | `flutter config --enable-macos-desktop` |
| Windows | Нужно включить | `flutter config --enable-windows-desktop` |
| iOS | Уже есть | Покрывает и iPhone (мобильный макет), и iPad (десктопный макет) |
| Web | Уже есть | Действий не требуется |

Отдельной цели платформы iPad нет — через адаптивную точку перелома он попадает в диапазон TABLET и получает десктопный макет.

## Адаптивные точки перелома

| Точка перелома | Диапазон | Режим макета |
|------|------|----------|
| PHONE | 0 - 767 | Ящик (AppBar + Drawer) |
| TABLET | 768 - 1199 | Сворачиваемая боковая панель (по умолчанию свёрнута, 64px) |
| DESKTOP | 1200 - 2460 | Боковая панель (по умолчанию развёрнута, 240px) |

Минимальная ширина iPad в портретной ориентации — 768px, попадает в TABLET, получает макет с боковой панелью.
Ширина iPhone всегда меньше 768px, попадает в PHONE, получает ящик.

## Изменения файлов

### 1. main.dart — настройка точек перелома

- `PHONE`: 0-767, `TABLET`: 768-1199, `DESKTOP`: 1200-2460
- Остальной код не меняется

### 2. admin_layout.dart — адаптивное переключение навигации

- `_isPhone`: попадание в точку перелома PHONE
- `_buildPhoneLayout()`: Scaffold + AppBar + Drawer, NavigationDrawer внутри Drawer переиспользует те же пункты меню, что и десктопная боковая панель
- `_buildDesktopLayout()`: существующий макет Row (боковая панель + верхняя панель + область содержимого)
- На TABLET боковая панель свёрнута по умолчанию, на DESKTOP — развёрнута

### 3. app_theme.dart — дополнение тёмной темы

- Извлечь стили компонентов в приватные константы `_dataTableTheme`, `_cardTheme`, `_inputDecorationTheme`, `_dividerTheme`
- Светлая и тёмная темы используют один и тот же набор стилей компонентов
- Тёмная тема: Material 3 + тот же seed + яркость dark
