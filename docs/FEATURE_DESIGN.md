> Copyright (c) 2026 erik <erik@erik.xyz> — https://erik.xyz

## 1. 系统概述

开放ERP系统 (open-erp) 是基于 webman v2 + Flutter 构建的全栈企业资源计划系统，覆盖系统管理、进销存、财务、CRM、审批工作流、消息通知、项目管理、人力资源、生产制造、自定义报表十四大业务域。

### 1.1 设计目标
- 单体部署，模块化设计
- 所有ID通过 snowflake 生成 + hashids 加密传输
- 敏感数据双层加密（传输层 AES-256-CBC + 存储层 AES-128-ECB）
- 移动加权平均成本核算
- 跨模块自动联动（采购→应付、销售→应收、收付款→核销）

### 1.2 技术约束
- PHP 8.3+, MySQL 8.0+, Redis 7, Elasticsearch 8
- 表前缀 erik_, 主键 BIGINT 非自增
- API 版本通过请求头 API-Version 控制
- JWT 认证 + RBAC 权限
- 全局函数不加 \ 前缀

## 2. 系统管理模块

### 2.1 用户管理
- 管理员 CRUD，支持批量启/禁用、批量软删除
- Excel 批量导入（逐行校验+错误报告）
- 密码 bcrypt 哈希，修改密码需原密码确认
- 删除操作需当前用户密码二次确认
- 手机号/邮箱/身份证号加密存储，列表自动脱敏

### 2.2 角色权限 (RBAC)
- 角色 CRUD，slug 唯一标识
- 权限树（无限级 parent_id 自引用），类型：菜单/按钮/API
- 权限标识格式: {method}.{path}（如 get.admin/product, post.admin/user/batch/destroy）
- 角色-权限多对多关联
- 超级管理员(super_admin)跳过所有权限检查
- AdminPermission 中间件 Redis 缓存权限（TTL=60s）

### 2.3 系统配置
- 键值对存储，支持分组
- 值类型: string|int|bool|json|array

### 2.4 操作审计
- 自动记录所有 POST/PUT/DELETE 操作
- 记录: 操作人、动作、方法、路径、IP、参数（敏感字段脱敏）、时间
- 8 平台来源端自动检测（Web/Flutter/HarmonyOS/API 等）
- 仅支持查询，不可删除/修改

### 2.5 安全防护
- 18 层纵深防御（详见 SECURITY.md）
- SecurityFilter: HTTP方法限制 + XSS/SQL注入/路径遍历/命令注入/CSRF 拦截
- RateLimit: Redis 滑动窗口限流（Lua 原子化，60次/分钟）
- 点击验证码（登录/注册强制）
- 账号锁定: 5次失败锁15分钟
- 并发会话限制: 同用户最多3个Token
- CSP 头、security.txt (RFC 9116)
- poster-php 敏感操作随机二次验证

## 4. 采购模块

### 4.1 采购流程
申请 → 审批 → 订单 → 收货 → 结算

### 4.2 采购申请
- 部门/人员提交采购需求
- 状态: 待审批 → 已批准/已驳回 → 已转订单
- 支持审批人操作

### 4.3 采购订单
- 关联供应商、商品明细（数量、单价、金额）
- 状态: 待审核 → 已审核 → 部分收货 → 已收货 → 已取消
- 可基于采购申请创建，也可直接创建

### 4.4 采购收货（跨模块联动）
- 按订单收货，支持分批收货
- 收货时自动触发:
  1. InventoryService.stockIn() → 更新实时库存 + 重算移动加权平均
  2. FinanceService.createAp() → 生成应付记录
  3. 更新订单已收数量和状态
- 支持库位、批次号记录

### 4.5 采购退货
- 退回供应商，生成出库冲销
- 关联收货单

### 4.6 供应商结算
- 按供应商汇总: 采购金额、已付、应付
- 结算状态: 未结算/部分结算/已结算

### 5.2 报价单

## 6. 库存模块

### 6.1 库存管理
- 实时库存: 仓库+库位+批次+SKU 四维精度
- 出入库流水: 所有库存变动统一记录（方向、数量、成本价、来源单号）
- 批次追踪: 生产日期、过期日期
- 序列号追踪: 唯一序列号，出入库时记录状态（在库/已出）

### 6.2 成本核算
- 移动加权平均法
- 公式: 新均价 = (原有库存总值 + 本次入库总值) / (原有库存数量 + 本次入库数量)
- 每次入库自动重算，出库按当前均价计成本
- 完整成本记录链（变动前均价 → 变动后均价）

### 6.3 库存调拨
- 仓库间/库位间调拨
- 状态: 待调拨 → 已调出 → 已调入 → 已完成
- 自动生成调出/调入出入库流水

### 6.4 盘点管理
- 计划盘点（按仓库/分类）+ 动态盘点（按SKU）
- 记录账面数量 vs 实盘数量
- 盘点差异自动生成盘盈/盘亏出入库流水

### 6.5 库存预警
- 按 SKU+仓库 设置上下限
- 低于下限/高于上限自动记录预警日志

## 7. 财务模块

### 7.1 会计科目
- 科目树: 资产/负债/权益/收入/费用 五大类
- 科目编码唯一
- 余额方向: 借方/贷方

### 7.2 记账凭证
- 凭证编号、日期、摘要
- 复式记账: 每笔分录包含借方金额和贷方金额（借贷必相等）
- 状态: 草稿 → 已审核

### 7.3 总账
- 按会计科目+会计期间（年度/月份）汇总
- 记录: 期初借方/贷方余额、本期借方/贷方发生额、期末借方/贷方余额
- 期末余额 = 期初余额 ± 本期发生额（根据科目余额方向）
- 凭证审核后自动更新
- 支持按年度/月份/科目筛选

### 7.4 明细账
- 指定科目的每笔凭证分录逐笔记录
- 包含: 凭证号、方向(借/贷)、金额、余额、摘要、日期
- 支持按科目+日期范围查询
- 与凭证分录同步更新

### 7.5 资产负债表
- 按会计期间生成（月度/年度）
- 自动汇总总账余额:
  - 资产类科目(1) → 总资产 = 流动资产 + 非流动资产
  - 负债类科目(2) → 总负债 = 流动负债 + 非流动负债
  - 权益类科目(3) → 所有者权益
  - 恒等式: 资产 = 负债 + 所有者权益
- 支持快照保存（JSON完整数据）
- 如无快照则自动从总账生成

### 7.6 现金流量表
- 按会计期间生成（月度/年度）
- 三分类:
  - 经营活动现金流量（销售收款 - 采购付款 - 费用支出）
  - 投资活动现金流量
  - 筹资活动现金流量
- 期初/期末现金余额 = 所有银行账户期初/期末余额合计
- 自动汇总现金银行日记账生成
- 支持快照保存（JSON完整数据）

### 7.7 应收应付
- 由采购收货/销售发货自动生成
- 应收: 类型=应收, 关联客户, 来源=销售发货单
- 应付: 类型=应付, 关联供应商, 来源=采购收货单
- 状态: 未核销 → 部分核销 → 已核销
- 同一来源单据不可重复生成（幂等保护）

### 7.8 收款管理
- 多账户（现金/银行/微信/支付宝）
- 审核后自动更新银行账户余额和现金日记账
- 核销: 选择应收记录，输入核销金额（不超过未核销余额）
- 部分核销状态自动流转

### 7.9 付款管理
- 同收款逻辑，方向相反
- 核销应付记录

### 7.10 现金银行日记账
- 按账户+日期记录每笔收支
- 记录变动后余额
- 银行账户余额实时更新

### 7.11 费用报销
- 流程: 提交 → 审批 → 打款
- 关联费用科目
- 打款后自动生成付款单 + 日记账

### 7.12 利润表
- 按月汇总: 营业收入、营业成本、费用、利润
- 数据快照存储（year+month 唯一）

### 7.13 固定资产折旧
- 资产全生命周期管理: 购置 → 使用 → 折旧 → 处置
- 折旧方法: 直线法（(原值-残值) / 使用月数）
- 按月计提折旧，自动生成折旧记录
- 记录: 原值、残值、使用年限、月折旧额、累计折旧、净值

### 7.14 税务管理
- 多税种支持: 增值税/企业所得税/个人所得税/印花税
- 税率可灵活配置
- 与采购/销售单据关联，自动记录税额

### 7.15 多币种
- 币种管理: CNY/USD/EUR/JPY 等
- 本位币标识
- 汇率按生效日期管理
- 支持外币折算

### 7.16 预算管理
- 年度预算编制: 按成本中心+科目+月份编制
- 预算 vs 实际对比分析
- 执行率计算 + 差异分析
- 状态: 草稿 → 已审批 → 执行中 → 已关闭

### 7.17 成本中心/利润中心
- 树形层级结构
- 成本归集 + 费用分摊
- 利润中心独立核算

## 8. CRM 模块

### 8.1 客户管理
- 客户档案与基础数据客户关联
- 客户下多个联系人（首要联系人标记）
- 联系人电话/邮箱加密存储

### 8.2 跟进记录
- 跟进方式: 电话/拜访/邮件/消息/其他
- 记录跟进内容、下次跟进计划、下次跟进时间
- 关联客户、联系人、商机

### 8.3 营销活动
- 活动全生命周期: 计划 → 进行中 → 已完成 → 已取消
- 多渠道: 邮件/短信/电话/活动/社交媒体
- 参与客户跟踪，转化率统计
- 预算 vs 实际花费对比

### 8.4 服务工单
- 工单管理: 待处理 → 处理中 → 已解决 → 已关闭
- 优先级: 低/中/高/紧急
- 分类: 技术支持/投诉/咨询/退换货/其他
- 分配处理人 + 回复（公开/内部备忘）
- 解决率统计

### 8.5 客户分析报表
- 6 大核心指标: 新增客户/活跃客户/留存率/客单价/CLV/工单解决率
- 报表自动生成（JSON数据快照）
- 支持月度/季度/年度

### 8.6 销售漏斗
- 阶段配置: 初步接触(10%) → 需求确认(30%) → 报价方案(50%) → 商务谈判(70%) → 成交(100%) → 输单(0%)
- 商机: 客户、当前阶段、预估金额、成交概率、预计成交日期、负责人
- 商机状态: 输单/进行中/已成交
- 阶段移动跟踪

### 8.7 客户公海池
- 客户公海池: 未分配归属或超时未跟进的客户自动进入公海
- 回收规则: 按客户等级设置无跟进自动回收天数
- 每人最大领取数限制，防止客户资源沉淀
- 领取/释放/回收操作均有流水记录
- 促进销售团队活跃度，避免客户沉淀

### 8.8 CRM报价管理
- 独立于销售模块的CRM内部报价流程
- 状态: 草稿 → 已发送 → 客户确认 → 已转合同 → 已失效
- 支持报价有效期
- 支持直接转换为合同（`to-contract`）
- 关联客户和商机

### 8.9 合同管理
- 合同全生命周期: 草稿 → 待审批 → 已审批 → 执行中 → 已完成/已终止
- 关联客户、商机、报价
- 合同明细：商品/数量/单价/金额
- 记录签订日期、开始/结束日期
- 合同条款内容（TEXT大字段）
- 负责人分配

- 状态: 待生产 → 生产中 → 已完工 → 已关闭
- 开工/完工操作: 记录实际开始/结束时间
- 生产明细: 领料清单（基于 BOM 展开）

### 13.3 工艺路线
- 工艺路线定义: 产品、工序序列、各工序标准工时
- 关联 BOM 和工作站

### 13.4 工作站
- 工作站 CRUD: 名称、编码、类型、产能、状态
- 关联工艺路线工序

### 13.5 MRP (物料需求计划)
- MRP 计划: 基于销售订单/生产计划 + BOM 计算物料需求
- 自动生成采购建议（原材料不足时）和生产建议（半成品不足时）
- MRP 明细: 物料、毛需求、库存可用量、净需求、建议订单量
- 计划状态: 草稿 → 已生成 → 已下达采购/生产建议

## 14. 自定义报表模块

### 14.1 报表定义
- 报表模板 CRUD: 名称、描述、数据集、字段、筛选条件、图表类型
- 数据集: 预定义 SQL 查询或模型方法
- 报表字段: 列名、显示名、数据类型、排序
- 筛选器: 字段、操作符、默认值

- 执行报表生成数据: 应用筛选条件、排序、分页
- 结果展示: 表格或图表（通过前端渲染）
- 支持导出

### 14.3 定时调度
- 报表定时任务: 指定报表、执行频率（cron）、接收人
- 调度状态: 启用/禁用
- 执行历史查询
