## 1. 系统管理

### 1.1 用户管理
- 管理员账户全生命周期管理（创建/编辑/删除/启禁用）
- 批量操作：批量删除、批量启用/禁用
- Excel 批量导入用户，逐行校验 + 错误报告
- 密码 bcrypt 哈希存储，修改密码需原密码确认
- 删除等敏感操作需当前用户密码二次确认
- 手机号/邮箱/身份证号加密存储，列表自动脱敏

### 1.2 角色权限 (RBAC)
- 角色管理：创建/编辑/删除，slug 唯一标识
- 权限树：无限级树形结构，三种类型——菜单(导航可见)、按钮(页面内操作)、API(接口访问)
- 权限标识格式: `{method}.{path}`，如 `get.admin/product`、`post.admin/user/batch/destroy`
- 角色-权限多对多关联，超级管理员跳过所有权限检查
- AdminPermission 中间件 Redis 缓存用户权限（TTL=60s）

### 1.3 系统配置
- 键值对存储，支持分组管理
- 值类型: 字符串/整数/布尔/JSON/数组

### 1.4 操作审计
- 自动记录所有 POST/PUT/DELETE 操作
- 记录操作人、动作、方法、路径、IP、参数（敏感字段脱敏）、时间
- 8 平台来源端自动检测（Web/Flutter/HarmonyOS/API 等）
- 只读查询，不可删除或修改

### 1.5 安全防护
- 18 层纵深防御：HTTP方法限制、XSS/SQL注入/路径遍历/命令注入/CSRF拦截
- 点击验证码（登录/注册强制校验）
- Redis 滑动窗口限流（Lua 原子化，默认60次/分钟）
- 账号锁定：5次失败锁定15分钟
- 并发会话限制：同一用户最多3个有效Token
- CSP 头、security.txt (RFC 9116)
- 敏感操作随机二次验证（poster-php）

## 3. 采购管理

### 3.1 采购申请
- 部门/人员提交采购需求
- 审批流程：待审批 → 已批准/已驳回 → 已转订单
- 可接入审批工作流引擎

### 3.2 采购订单
- 关联供应商、商品明细（数量、单价、金额）
- 状态：待审核 → 已审核 → 部分收货 → 已收货 → 已取消
- 可基于申请创建，也可直接创建

### 3.3 采购收货（跨模块联动）
- 按订单收货，支持分批
- 收货自动触发：① 入库（移动加权平均成本核算）② 生成应付记录 ③ 更新订单已收数量

### 3.4 采购退货
- 退回供应商，生成出库冲销

### 3.5 供应商结算
- 按供应商汇总：采购金额、已付、应付
- 状态：未结算/部分结算/已结算

## 5. 库存管理

### 5.1 实时库存
- 四维精度：仓库 + 库位 + 批次 + SKU
- 支持多仓库、多库位
- 实时库存查询

### 5.2 出入库流水
- 所有库存变动统一记录（方向、数量、成本价、来源单号、时间）

### 5.3 批次追踪
- 生产日期、过期日期、批次号
- 出入库时记录批次

### 5.4 序列号追踪
- 唯一序列号管理
- 出入库时记录状态（在库/已出）

### 5.5 成本核算
- 移动加权平均法
- 公式: 新均价 = (原库存总值 + 本次入库总值) / (原库存数量 + 本次入库数量)
- 每次入库自动重算，出库按当前均价计成本

### 5.6 库存调拨
- 仓库间/库位间调拨
- 状态：待调拨 → 已调出 → 已调入 → 已完成
- 自动生成调出/调入流水

### 5.7 盘点管理
- 计划盘点（按仓库/分类）+ 动态盘点（按SKU）
- 记录账面 vs 实盘数量
- 差异自动生成盘盈/盘亏流水

### 5.8 库存预警
- 按 SKU+仓库 设置上下限
- 低于下限/高于上限自动记录预警日志

## 6. 财务管理

### 6.1 应收应付
- 由采购收货/销售发货自动生成
- 状态：未核销 → 部分核销 → 已核销
- 同一来源单据幂等保护

### 6.2 收款管理
- 多账户（现金/银行/微信/支付宝）
- 审核后自动更新账户余额和现金日记账
- 支持核销应收记录

### 6.3 付款管理
- 同收款逻辑，方向相反
- 支持核销应付记录

### 6.4 现金银行日记账
- 按账户+日期记录收支流水
- 银行账户余额实时更新

### 6.5 费用报销
- 流程：提交 → 审批 → 打款
- 打款后自动生成付款单 + 日记账

### 6.6 利润表
- 按月汇总：营业收入、营业成本、费用、利润
- 快照存储（year+month 唯一）

### 6.7 固定资产
- 资产全生命周期：购置 → 使用 → 折旧 → 处置
- 直线法折旧：(原值-残值) / 使用月数
- 按月计提折旧，自动生成折旧记录
- 记录：原值、残值、使用年限、月折旧额、累计折旧、净值

### 6.8 税务管理
- 多税种：增值税/企业所得税/个人所得税/印花税
- 税率灵活配置（含4个默认税率种子数据）
- 与采购/销售单据关联，自动记录税额

### 6.9 多币种
- 币种管理：CNY/USD/EUR/JPY（含4个默认币种种子数据）
- 本位币标识
- 汇率按生效日期管理

### 6.10 预算管理
- 年度预算编制：按成本中心 + 科目 + 月份
- 预算 vs 实际对比分析（执行率 + 差异）
- 状态：草稿 → 已审批 → 执行中 → 已关闭

### 6.11 成本中心/利润中心
- 树形层级结构
- 成本归集 + 费用分摊
- 利润中心独立核算

## 跨模块数据流

```
采购收货 → 自动入库(移动加权平均成本) → 生成应付记录
销售发货 → 自动出库 → 生成应收记录
收付款 → 核销应收应付 → 更新日记账
盘点差异 → 自动生成盈亏出入库流水
审批提交 → 工作流引擎路由 → 逐级审批 → 通知推送
费用报销打款 → 自动生成付款单 + 日记账
资产折旧 → 按月计提 → 成本分摊到成本中心
MRP 运算 → BOM 展开 → 净需求计算 → 生成采购/生产建议
请假审批 → 通过后更新考勤状态
生产完工 → 自动入库(产成品) + 扣减原材料库存
工时记录 → 汇总到任务 → 聚合到项目成本
```

## 17. 仓储管理 (WMS)

### 17.1 库区库位
- **库区**：收货区/存储区/拣货区/打包区/发货区/退货区/质检区
- **库位扩展**：巷道→货架→层→货位 层级 + 条码/容积/承重/拣货顺序

### 17.2 入库流程
- **ASN(预到货通知)**：供应商→预计到货→承运商→追踪号
- **收货任务**：月台收货→实收数量录入→质检
- **上架任务**：自动生成→指派→策略(fifo/zone_fixed/abc)→确认上架(stockIn)

### 17.3 出库流程
- **波次管理**：多订单聚合→拣货波次/发货波次→优先级
- **拣货任务**：按单/批量/分区/波次拣货→指派→确认(实拣数量)
- **打包任务**：包装类型(box/bag/pallet)→重量/尺寸

- **费率卡**：起运地/目的地→重量段→基础费/每kg费/燃油附加费
- **多币种**：CNY/USD/EUR等，关联 exchange_rate
- **运费比价**：按目的国+重量查询所有可用费率，升序排列

### 18.3 运单与轨迹
- **运单**：承运商服务→追踪号→状态(待发货→已取件→运输中→已送达/异常/退回)
- **物流轨迹**：webhook回调→自动同步运单状态
- **运费发票**：创建→确认→付款→生成AP
